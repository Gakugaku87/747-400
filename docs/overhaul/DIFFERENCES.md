# 実機との違い（DIFFERENCES）

Sparky744（この作業ツリーの機体）が、実機の 747-400 とどこで違うかを、全分野についてまとめたもの。2026-10-27 の時点（`overhaul`、表示 5-2 の段 7 まで、FMC・CDU は 6-1・6-2 の段 7e3b まで）。

- 元の調査は [GAP_ANALYSIS.md](GAP_ANALYSIS.md)（作り直し前のコードと資料の読み比べ、550 件）。ここでは、その後の作り直しで直った点を反映し、残っている違いを分野ごとに短く書いた。各項目の括弧は GAP の ID で、詳しい内容と出典は GAP_ANALYSIS.md と `notes/` にある。
- 基準の機体は FCOM の 109（旅客機、PW4056）。405（PW の改造貨物機）と 570（GE の貨物機）の違いは notes に書いてある。RR には資料が無い。
- 「推定」と書いたものは、資料に値や記載が無いので決めた部分（全部の一覧は [PROGRESS.md](PROGRESS.md) の「推定で作った部分」）。
- 作り直した分野は、X-Plane での試験（Web API と FlyWithLua の記録）まで済ませている。残っている違いの多くは、まだ作り直していない分野のもの。

## 2. 分野ごとの違い

### 電源（ATA 24）：作り直し済み（1-1）

実機に合わせた点：バス単位のモデル（AC 1〜4、同期バス、SSB、transfer bus、standby、ground service・ground handling、DC 1〜4、バッテリー母線）、電源の切替（LH24 の表と FCOM）、GCB・BTB の許可、standby 電源、ELEC GEN OFF・ELEC AC BUS・ELEC BUS ISLN、DRIVE 灯と DRIVE DISC、ELCU の load shed（簡略）、バッテリーの表示と BAT DISCH、air mode。P5 の灯、EICAS、表示器と CDU の電源もモデルから。カスタム acf の ELEC synoptic（ISLN・DRIVE の枠、UTILITY と GALLEY を母線ごとの色で）と STAT のバッテリー値・CHG/DIS。

残っている違い：
- 保護トリップ、3.5 秒の break power transfer、last source on が無い（ELEC-04）。故障の仕組みがまだ無い。
- 手動の SSB スイッチ・OPEN 灯、GEN FIELD MAN RESET・FIELD OFF 灯が無い（3D にも操作子が無い。ELEC-05・22）。
- 客室側の ground service switch が無い（ELEC-13）。
- autoland のバス分離が無い（ELEC-18。AFDS の作り直しで）。
- 故障で出る status（ELEC DRIVE、BAT CHARGER、ELEC TR UNIT、ELEC IDG VALVE）が無い（ELEC-23）。
- 外部電源は XP12 では X-Plane の GPU 電圧に依る（ELEC-17）。
- まだ X-Plane の bus 0 で電源を見る系統：機器冷却、IRS と無線、表示灯の輝度、客室灯、ヨーダンパー。
- 純正 acf の ELEC synoptic と STAT は前のまま（GALLEY は UTILITY と同じ色、STAT は X-Plane の値と固定の "DIS"）。freighter の galley 無し（570）は電源モデルにまだ無い。
- 推定：バッテリーの負荷電流と電圧の曲線、BAT DISCH までの 60 秒など。

### 空地判定（PSEU）：作り直し済み（1-2）

実機に合わせた点：主脚のトラックの傾きで左右とも接地したときに地上（片側だけなら空中）、pri・alt の 2 系統、前脚の圧縮。電源の air mode、脚レバーのロック、逆推力のロックアウト、燃料系はこれを使う。

残っている違い：
- autopilot、fms、計器、操縦系統、EEC、エンジン、油圧、脚（タイヤ圧）、manipulators、fdr、照明など 15 モジュールが、まだ X-Plane の「どれか 1 輪接地」（`onground_any`）を読む。各系統の作り直しで乗り換える。
- 推定：トラックの傾きは X-Plane の `eagle_claw_angle_deg`（胴体に対するトラックの角度）が 4° を超えたとき、前脚の圧縮は前輪の接地（X-Plane に傾きセンサーと strut の縮みが無い）。

### 乗員への警報（EICAS、警報音）：枠組みは作り直し済み（1-3）

実機に合わせた点：新しいメッセージはそのレベルの群の先頭（advisory は caution の下。2026-10-24 に直した）、CANC/RCL（メッセージごとの CANC 済みの印）、サイレン・ベル・beeper が警報モデルから鳴る（`.snd` の結線）、caution ごとの beeper、抑止（始動前、始動中、離陸、着陸）、メッセージ表のレベルと文言を FCOM に、ページ割り（カスタム acf は 10 ページまで）、0.1 秒ごとの更新、STATUS メッセージと STATUS cue。

残っている違い：
- 他のメッセージによる抑止と時間遅れは、系統ごとにまだ（各系統の作り直しで足す）。
- FCOM にあって表に無いメッセージが約 30 件（WARN-08。各系統で）。
- 離陸形態警報が「エンジン 2 と 3 の両方」を要求する（FCOM は 2 か 3）。着陸形態警報（CONFIG GEAR）は、着陸フラップ（フラップ 25 を含める）と「どれか 1 本のレバーが閉」（プラグインのレバーを 1 本ずつ）を操縦系統 4-1 段 3 で直したが、リセットの可否・脚上げ後の抑止などは無い（WARN-11・12。GND PROX GEAR OVRD での抑止は 5-1 段 4 で）。
- SPEEDBRAKES EXT の条件式（WARN-13）は操縦系統 4-1 段 3 で直した（空中の CONFIG SPOILERS も貨物機だけに）。>STAB GREENBAND が無い（WARN-14 の残り。グリーンバンドの 3 帯と CONFIG STAB の帯は操縦系統 4-1 段 2c で）。
- OVERSPEED を Vmo/Mmo でなくフラップ・脚の制限込みの Vmax で出す（WARN-15）。
- ALTITUDE ALERT が無い（WARN-16）。
- 失速警報（スティックシェーカー）は 5-2 段 3b で、今の Mach で必要な揚力が FCTM のシェーカー速度から作った境界を超えたときに出す（荷重倍数を含む。実機の SWMC の迎角の比べ方そのものではない：WARN-18 の残り）。
- GPWS の PULL UP・WINDSHEAR の master WARNING は 5-1 段 4 で作った（WARN-19）。
- PILOT RESPONSE、チャイムの論理、MAWEA の電源が無い（WARN-20〜22）。
- APU・貨物室・車輪格納部の火災のベルは、火災（3-4）で。
- 純正 acf のパネルは 2 ページまでしか描けない（PG も無い）。

### 油圧（ATA 29）：作り直し済み（1-4）

実機に合わせた点：EDP は圧力補償型、demand pump の AUTO（1400/1600 psi、タイマー、CUTOFF、系統 1・4 のフラップ）、ポンプの電源と抽気、AUX、火災スイッチ（SOV 閉・EDP 減圧・demand pump 起動）、舵面の系統の組の誤り 3 か所を修正、accumulator（系統 4 だけで充圧）、X-Plane の故障を書き換えない、P5 の灯、EICAS、作動油量（乱数をやめた）、リザーバの与圧と RSVR PRESS、STATUS、スタンドパイプ。カスタム acf の HYD synoptic（ポンプの記号を状態の色で、各系統と系統の組の不作動項目。P&W は THRUST REV つき）。

残っている違い：
- 系統の圧による制限：ステアリング（4-2 段 4：系統 1 の脚 DOWN 圧。HYD-12 は済）、脚（4-2 段 1：前脚・胴体脚は系統 1、翼脚は系統 4）、安定板トリム（4-1 段 2b：系統 2・3）、ヨーダンパー（4-1 段 4：上は系統 3、下は系統 2）は済。P&W の逆推力は、エンジン 2-3 で系統 n の圧が 1,000 psi 未満なら動かないようにした。
- ブレーキの効きは源（系統 4、1、2、accumulator）の圧で決まる（4-2 段 2。HYD-09 は済）。
- 油温に燃料の熱交換が無い（HYD-17）。
- 純正 acf の HYD synoptic は前のまま（色の付かない記号、組の中身が合わない不作動項目の絵）。
- FLT CONTROL HYD POWER（系統ごとの遮断弁）が無い（HYD-22）。
- 推定：舵面が動く圧 1000 psi、漏れ量、圧の立ち上がり、油温の上がり方、synoptic の不作動項目の組（1+2+4 の BRAKES）と RR の THRUST REV など。

### 空圧（ATA 36）：作り直し済み（1-5）

実機に合わせた点：需要と供給からのダクト圧（区画ごと）、エンジンの HPSOV・PRV・PRSOV、逆流防止、始動弁の条件（クロスブリードは供給側 70 % N2）、過熱ラッチとスイッチでのリセット、ISLN 弁の移動時間と VALVE 灯・BLEED ISLN（10 秒の不一致）、APU 弁（RUNNING ＋ 2 秒、OFF で閉）、ISLN の電源、STATUS の BLEED ASCTU。

残っている違い：
- 過熱・過圧・ダクトリークの故障がつながっていない（BLEED n、BLEED HP ENG、BLD DUCT LEAK。PNEU-03。X-Plane に相当する故障が無い）。
- 地上空気（エアカート）をつなぐ操作が無い（PNEU-07）。
- スターターの回り方：X-Plane のエアスターターはダクト圧で回る（3-1 で与圧を上書きしたので、X-Plane のダクトの空気にこちらのダクト圧を書いている）。圧と回り方の関係は X-Plane のもので、資料に無い（PNEU-08）。
- ECS synoptic の弁の記号に、PRSOV の琥珀の OFF と移動中の形が無い（PNEU-11 の残り。パネルの絵が無い）。主 EICAS のダクト圧の表示条件（PNEU-09）と synoptic の流れの線は 3-1 で直した。
- GE の逆推力のとき、HPSOV と PRV が BLEED スイッチ OFF でも開く動きが無い（PNEU-12）。逆推力の側は、エンジン 2-3 でそのエンジンが運転中なら動くようにしたが、過熱や始動弁で PRV が閉じていても動く。
- EEC の抽気補正は、運転中のパックの数と防氷弁で決め、実際の抽気源（APU からパックへ、エンジン抽気 OFF）を見ない（PNEU-13 の残り）。抽気による推力の損失は、エンジンが出す抽気の量からの推定（X-Plane の吸気温度の上昇として、パック 1 台分で 1 ℃）。
- 推定：流量（high flow のパック 1 台＝1 の単位）、ダクト圧の下がり方、弁の時間など、式と値の多く。

### APU（ATA 49）：作り直し済み（2-1）

実機に合わせた点：1 つの状態機械、START→ON で始動を保持、ドア全開で starter、60 秒の cooldown（抽気弁と発電機は無負荷）、自動停止（火災、燃料切れ、始動の失敗）と fault の保持、APU・APU DOOR・APU RUNNING を FCOM の条件で、STATUS の N2・油量。

残っている違い：
- 始動電源と始動回数の制限が無い（APU-09）。
- 空中の運用範囲（高度）が無い（APU-10。資料が自動停止を書いていない）。
- 油の消費と RF/LO が無い（APU-02）。抽気ダクト過熱の停止は入力が無い。
- エンジン始動時の増風要求が無い（APU-12）。
- 回転と EGT は X-Plane の APU のまま。
- 推定：ドアの開く時間 12 秒、APU DOOR の 20 秒、始動の打ち切り 120 秒、N2 = N1 × 0.926 など。

### 燃料（ATA 28）：作り直し済み（2-2）

実機に合わせた点：
- タンク・ポンプ・弁の表、圧力の順位（CWT ポンプ 2 台 ＞ O/J 2・3 ＞ 主ポンプ。CWT ポンプ 1 台は主ポンプ 2 台に勝てない）。
- クロスフィードのマニフォールド（開いた xfeed を通して他の主タンクからも）と吸引供給（ポンプが止まってもエンジンは止まらず、FUEL PRESS ENG）。SP.12 の均衡手順が成り立つ。
- xfeed 2・3 の自動閉（地上でフラップ 10〜20 に 40 秒、空中はフラップがその範囲を出るまで保持）、O/J 2・3 の起動条件、予備タンクの移送（主 2 か 3 が 18,200 kg で 4 弁とも、空中だけ）、CWT のスカベンジ（ジェットポンプ）、水平安定板タンクの移送（109）、shared flow。

- パックの過熱は、温度のモデルの出口が 135°F 以下なので原因が無く、故障の入力のまま。再循環ファンの故障の入れ方が無い（X-Plane に相当する故障が無い）。CPC の故障は `laminar/B747/air/fail/cpc[0-1]` で入れる。
- 外流弁の自動のモーター、パック弁の継電器、再循環ファンの電源のバスは資料に無い（どれかの AC で動くとした）。

### 防氷・防雨（ATA 30）：作り直し済み（3-2）

実機に合わせた点：
- NAI：弁はエンジンの PRV の下流の抽気で開く（ENGINE BLEED が OFF でも NAI で PRV が開く。始動弁が閉じて 15 秒、火災スイッチ、PRV の過熱ラッチは抽気のモデル）。28V DC のソレノイド、カウルの過熱で閉じてスイッチを切るまでラッチ。VALVE 灯は弁がスイッチの位置と違う間、NAI VALVE n はエンジン運転中に 3.5 秒。主 EICAS の NAI は弁が開いたとき。

残っている違い：

- 推定：NAI 弁の開く抽気 12 psi と全行程 1 秒、WAI 弁の全行程 2.5 秒、地上で WAI ON のとき VALVE 灯を点けないこと、プローブ・窓・ワイパーの電源のバス、X-Plane に無い AUX のプローブを予備のピトー・静圧孔に当てたこと。プローブの地上の減電力は作っていない。

### 酸素（ATA 35）：作り直し済み（3-3）

実機に合わせた点：
- 乗客酸素：客室高度約 14,000 ft で自動で作動し、PASS OXYGEN を ON にすればどの高度でも作動する。RESET は客室 12,000 ft 未満でだけ効く。作動中は PASS OXYGEN ON、60 秒で STATUS PASS OXYGEN ON。NO SMOKING と FASTEN SEAT BELTS は選択器にかかわらず点く（前はサインの判定に TODO があるだけで、酸素の系統が無かった）。

残っている違い：

- 純正 acf の STATUS ページには酸素圧が出ない（パネルを変えていない）。

### 火災防護（ATA 26）：作り直し済み（3-4）

実機に合わせた点：
- 検知：エンジンの火災と過熱、APU の火災に双ループの検知器（APU battery bus）。エンジンは 2 ループとも感じたときに警報し、片方のループが故障すればもう一方だけで警報する。APU はどちらかのループで警報。両ループの故障で >DET FIRE/OHT n・>DET FIRE APU。STATUS の loop のメッセージと FIRE/OVHT SYS（前は X-Plane の火災表示の素通しで、APU は故障の予約だけで灯が点いた）。
- メッセージ：FIRE ENG n、FIRE APU、OVHT ENG n NAC（新設）、>BTL LO L/R ENG A/B（前は FCOM に無い名前）、>BOTTLE LOW APU。FIRE のメッセージでベルと master WARNING が出る（1-3 の警報のモデル）。
- 消火スイッチ：火災警報・FUEL CONTROL の CUTOFF・試験で解錠され、それ以外は引けない（main hot battery bus）。Fire Override はコマンド。回した向きのボトルを 1 回だけ放出し、翼の 2 エンジンでボトルを共用する（空のボトルでは消えない。前は回している間ずっと X-Plane の消火器が入った）。BTL DISCH の灯。
- 消火スイッチを引くと、燃料弁・spar valve・抽気弁・油圧に加えて発電機の GCR がトリップし、スイッチを戻しても GEN CONT を OFF→ON にするまで戻らない（ラッチ式のリレー）。
- APU：火災で APU を止め（試験では止めない）、地上では APU が 95 % 未満のまま 10 秒で APU ボトルを自動で放出する。APU の消火スイッチ（引く・回す・override）はコマンド。APU BTL DISCH の灯。
- FIRE/OVHT TEST：押している間、消火スイッチ・APU・貨物の灯、>TEST IN PROG、5 秒で >FIRE TEST PASS（ループが 1 本でも故障か電源が無ければ FAIL。貨物・車輪格納部・ダクトの検知器も含む）。離すと消える。
- 下部貨物室：煙検知器（ゾーンごとに 2 ループ、電源投入と試験のときに組み替え）、FIRE CARGO FWD・AFT と灯、ARM・DISCH で A・B を即時に、C・D を 30 分後か接地で（前は ARM・DISCH を誰も読まず、灯も常に消えていた）。DISCH の灯、>CGO BTL DISCH、>CARGO DET AIR。
- 車輪格納部の火災（FIRE WHEEL WELL）、主翼前縁の過熱（BLD DUCT LEAK L・C・R）、化粧室とクルーレストの煙（>SMOKE LAVATORY、SMOKE DR 5 REST）。スクイブ試験（TEST 1・2 のコマンドと緑の灯）。

残っている違い：
- 貨物室の煙、車輪格納部の火災、ダクトリーク、化粧室・クルーレストの煙、ナセルの過熱は X-Plane に無いので、失敗の dataref（`laminar/B747/fire/fail/…`）で起こす。ダクトリークでダクト圧は下がらない（抽気の残り）。クルーレストの煙で給気弁とファンは止まらない。
- FUEL CONTROL の赤灯は 3D が X-Plane の火災表示に付いているので、X-Plane のエンジン火災では点くが、試験やループの故障の結果には合わない。APU の消火スイッチと Fire Override は 3D に操作子が無い（コマンドで操作）。M869（脚格納部の APU 火災パネル）と APU 火災のホーンの音は無い。
- 過熱の原因（X-Plane に無い）は失敗の dataref で起こす。
- 推定：ボトルが空になるまで 1.5 秒、X-Plane のエンジン火災は過熱の検知器に伝えないこと、APU ボトルで X-Plane の APU 火災を消すこと、貨物の剤で煙の失敗を消すこと、venturi の吸引の閾値（中央ダクト 5 psi）、貨物の検知の電源。
- 貨物機の主デッキの火災（FIRE-19）。

### 操縦系統（ATA 27）：作り直し中（4-1。フラップ・SRM・スピードブレーキ・横操縦・遮断弁・ヨーダンパーの INOP は済）

直した点：ラダートリムが舵面に入る（全行程の 80 %、比率変換器を通る。前は舵面が動かなかった）。舵面位置のスポイラーはスポイラー 4・12（前は平均）。フラップレバーのスナップ。

- 横操縦（段 4、横操縦のモデル）：エルロンは操縦輪の初めで大きく動き、約 45° で全舵角になる（ATA27 p.59 のプログラマの曲線。前は操縦輪の全行程 90° に比例し、10° で内側 2.2°、実機は 5.65°）。スポイラーは操縦輪 11° から動き始めて比例し（前は 0 から）、スピードブレーキを出しているときは下がる側の翼のスポイラーが下がる（ミキサー。前は上がる側にしか足さず、スピードブレーキ中のロールが弱かった）。スピードブレーキの段は p.165 の曲線（6・7 は 28° で 20°、49° で 45°）。スポイラー 6・7 と主翼 2 のスポイラー（4・9）が X-Plane の空力に入る（前は動いていなかった：6・7 は 3D と表示だけ、4・9 は一部の面が動かなかった）。エルロントリムいっぱい（6 units）は操縦輪 47°（前は操縦輪いっぱいで、権限が約 2 倍）。
- FLT CONTROL HYD POWER とヨーダンパー（段 4 の後半）：翼と尾翼の遮断弁が系統ごとに閉じられ（3D にスイッチが無いのでコマンド）、閉じた系統はその舵面に効かない。VALVE CLOSED 灯と >FLT CONT VLVS（前は灯が常に消え、何も起きなかった）。ヨーダンパーは電源（上は AC standby と電池バス、下は AC 1 と DC 1）・IRU の整列・故障で INOP と >YAW DAMPER UPR、LWR になる（前はスイッチと IRU の選択器とバッテリーのスイッチだけ）。作動筒は系統 3（上）・2（下）が要る（前はラダーのどの系統でも効いた）。

- スピードブレーキ（段 3、スピードブレーキのモデル）：自動スピードブレーキは機体側で作った（前は X-Plane 本体の自動展開：ARM で −0.5）。地上で推力レバー 1・3 がアイドル、系統 1 か 4 の圧と PSEU の地上で、ARM ならレバーが UP まで動き、DN でもリバースレバー 2・4 を引けば UP（RTO と ARM し忘れ。前はどれかのエンジンの reverse で上げていた）。推力レバー 1 か 3 を進めると DN に戻る（地上で手で出したときも。go-around の保護。前は無かった）。空中で手で出したスピードブレーキは戻らない。DC bus 1 が要る。SPEEDBRAKE AUTO と STATUS（前は立たなかった）。>SPEEDBRAKES EXT は、レバーが ARM より後ろで RA 15 ft 超のとき、RA 800 ft 以下・着陸フラップ（25・30）・推力レバー 2 本以上が speedbrake power level より前のどれか（前は条件式の結合の誤りで推力の条件が抜け、フラップ 25 を着陸フラップと見なかった）。空中の CONFIG SPOILERS（赤）は貨物機（405・570）だけ（前は全機）。推力レバーはどれも 3D のレバー（プラグインの `engine/throttle`）で見る。

- 安定板トリム（段 2b、SRM のモデル）：速さは 1 unit = 1°（ATA22 p.132）で、両方の STCM で 220 kt 以下 0.5 units/s・230 kt 以上 0.2、片方で半分（前は X-Plane のコマンドで対気速度に依らず約 0.3 units/s）。電気トリムの範囲 1.8（脚 down か前縁が出ていると 0.8）〜11.6、ALTN 0.25〜14.75（前は 0〜15 のどこまでも）。操縦桿をトリムと逆に引くと止まる（column cutout）。機長と F/O のスイッチが逆なら動かない。A/P 1 台で操縦輪のスイッチを使うと A/P が外れ（AUTOPILOT DISC）、2 台以上では効かない。ALTN は A/P を外さず、A/P 中に使うと STAB TRIM UNSCHD。油圧 2・3 の片方を失うか cutout スイッチを CUTOUT にすると半分の速さで >STAB TRIM 2・3、暴走は自動遮断で止まる（>STAB TRIM。cutout が ON なら STAB TRIM UNSCHD）。オートトリムは SRM がその SRM の STCM で半分の速さ、3.5 秒の遅れの後に動かす（前は狙いの約 1/60 の速さ）。A/P が外れると A/P の昇降舵・補助翼の指令は 0 に戻る（前は残り、操縦桿の位置がずれた）。STATUS の STAB TRIM・STAB TRIM UNSCHD・STAB AUTO TRIM。ALTN と cutout スイッチは 3D に操作子が無いので、コマンドで操作する。
- speed trim とグリーンバンド（段 2c）：A/P が外れていて 220 kt 以下なら、離陸 20 秒後から安定板が速度に応じて動く（120〜220 kt で 2.55 units 機首上げ、係合時の速度と位置から。ATA22 p.159）。前は無かった。STATUS STAB SPEED TRIM。グリーンバンドは 3 帯（mid 3.35–8.15、nose up 3.35–10.15、nose down 1.35–8.15）から選ばれ、地上で V1 未満なら指示器に出て、V1 を超えると mid に戻る。CONFIG STAB は選ばれた帯で判定する（前は FMC トリム ±2.25 units の帯で、帯の上端・下端が実機と違った）。

- 外側エルロンのロックアウトとラダー比変換器（段 2a、SRM のモデル）：ロックアウトは、前縁 group A が入っていて 238 kt か M .53 を超えるとロック、group A が出るか 232 kt と M .51 を下回ると外れ、間は保つ（前は 232→238 kt の直線で、フラップも Mach も見なかった）。SRM の故障で他方が引き継ぎ、両方失うと空中ではロックを外す。アクチュエータが動かないと 90 秒で AILERON LOCKOUT。ラダー比変換器は上下別々に速度の表（155.5 kt まで全権限、450 kt で 5°）で動き、エアデータを失うと上は 329 kt・下は 209 kt の位置、autoland では全権限、故障した変換器はその位置のまま（RUD RATIO SNGL・DUAL）。ペダルとラダートリムを足してから比変換器を通すので、高速で舵角が比の上限を超えない（前は和が制限されず、450 kt でも 9° 近く出た。空中ではトリムが二重に効いてもいた）。
- フラップ（段 1、FCU のモデル）：後縁は内側（系統 1）・外側（系統 4）の群ごとに油圧の主系統と電動の副系統。指令して 1400 psi 未満が 4 秒、または動かないまま 7 秒（脚の動作中は 42 秒）で副系統（FLAPS PRIMARY）。圧が戻れば主系統に、圧があるのに副系統になった群は格納して 10 秒で戻る。2000 psi の priority valve。副系統で 25 秒動かないか、左右の差が 6.2 %（内側）・3.4 %（外側）を超えると、その群は止まる（FLAPS DRIVE）。前縁は内側・中央・外側の群ごとに空気圧（各翼のダクト圧）と電動。動かないと 30 秒で両翼とも電動（内側と中央は一緒）、指令の位置に着くと空気圧に戻る。電動は空気圧の 10 倍の時間（約 90 秒）。代替フラップ（ARM で FLAPS CONTROL、レバーは効かず、EXT で全群が電動ですぐ動き後縁は 25 で止まる、RET で前縁は内側の後縁が UP になってから）。順序（1 で group A、5 で group B と後縁、格納は内側の後縁が 4.5° 未満で group B、外側の後縁が UP で group A）。地上の逆推力（1・4 か 2・3）で group A を格納。荷重軽減は後縁が両方とも主系統のときだけ。EICAS の表示は、UP と 1 の間は group A の動き、1 から上は最も遅い後縁の群。マゼンタはレバーの位置に全部が着くまで。副系統・停止・非対称・代替で拡大の表示。STATUS の TE FLAPS・LE SINGLE DRIVE・LE MULT DRIVE・FLAP CONTROL・FLAP LOAD RELIEF。外側フラップの wing 2 の部分（acf のフラップの組 2）も動く（前は空力上 0°）。

残っている違い：

- フラップ：拡大・代替の表示のパネル（前縁の 6 箱、琥珀、amber X、代替の目盛り：FCTL-12）が無く、拡大は後縁 4 本だけ。後縁の主系統の速さ（30° を 45 秒）と副系統の速さ（その 1/10）、前縁の電動の故障で止まるまでの時間、前縁の制御の電源は資料に無く推定。逸走と moving away の保護は作っていない（故障の源が無い）。故障は `laminar/B747/flt_ctrls/fail/...` で入れる。

### 航法センサーと無線（ATA 34）：作り直し中（5-1 段 1：エアデータ、段 2：IRS、段 4：電波高度計・GPWS、段 5：トランスポンダ・TCAS、段 5c：気象レーダー、段 5d：PFD の TCAS RA の表示は済）

## 3. X-Plane の上で作ることによる違い

- 推力・燃料流量・空力は X-Plane の計算。燃費は acf の SFC で決まる（燃料 2-2 で値を確かめる）。
- カスタム acf の失速の速さを FCTM の失速速度に合わせた（2026-10-25、利用者の承認：主翼の翼型の失速を早め、前縁スラットの効きを下げた。ACF_DIFF.md §5、notes/FCTM.md §1.14）。前は約 270 t・10,000 ft でクリーンの 1 g 失速が約 153 kt（FCTM 173 kt）、フラップ 10・20・30 は昇降舵いっぱいでも失速しなかった。後の FCTM との差は UP −2、10 +6、20 −5、30 +4 kt（測り直すと ±3 kt ほどばらつく）。X-Plane の後縁フラップの揚力の増え方が実機と違う（角度とともに頭打ち）ので、フラップごとに数 kt の差が残る。実際の失速から段 3b のシェーカー（FCTM のシェーカー速度）までの余裕は、10 と 30 で約 2 kt（実機は 6〜7 kt）、20 で約 10 kt、UP で約 23 kt。
- 脚・ブレーキ・オートブレーキ・ブレーキ温度は機体側で作った（4-2 段 1〜3・5）。X-Plane へは脚の位置・ブレーキの比・パーキングブレーキの比を書き、制動・タイヤ・ABS の計算は X-Plane。ステアリング（段 4）も機体側で角度を決め、X-Plane へは前輪と胴体脚の角度を書く。逆推力は、動ける条件は作り直したが、展開・格納の動きと推力は X-Plane の計算。
- 与圧は X-Plane の与圧に値を書いている（空調 3-1 まで）。
- 経路と ND の経路線は X-Plane 標準の FMS（FMC の作り直しまで）。
- X-Plane 側の制約（試験で見つけたもの）：機体を読み直さずにフライトを始めると前のフライトの状態が残る系統がある。XP12 の外部電源は X-Plane の GPU 電圧に従う。X-Plane の抽気のモードと isolation valve は連動する。Web API の長さ 0 のコマンドは離す操作が届かない。
