# 実機との違い（DIFFERENCES）

Sparky744（この作業ツリーの機体）が、実機の 747-400 とどこで違うかを、全分野についてまとめたもの。2026-10-31 の時点（`overhaul`、表示 5-2 の段 7 と MAP CTR まで、FMC・CDU は 6-1・6-2 の段 9e1（性能 DB・ECON・軌跡の予測・風、自動操縦と A/T が FMC の VNAV で飛ぶ、MCP の高度のノブの押しと RESET MCP ALT、早期降下と cruise climb・descent、DES NOW・DES DIR・CLB DIR）まで、自動操縦は 6-3 の段 6c まで、オートスロットルは 6-4（FMC の段 9f：モードの論理・制御則と servo・interlock）まで、カスタム acf の空力とエンジンは FCOM・ICAO との比べ合わせ（5f）を済ませ、フラップの揚力の形は補正した）。

- 元の調査は [GAP_ANALYSIS.md](GAP_ANALYSIS.md)（作り直し前のコードと資料の読み比べ、550 件）。ここでは、その後の作り直しで直った点を反映し、残っている違いを分野ごとに短く書いた。各項目の括弧は GAP の ID で、詳しい内容と出典は GAP_ANALYSIS.md と `notes/` にある。
- 基準の機体は FCOM の 109（旅客機、PW4056）。FCOM が P&W の 109 と GE の 570（GE の貨物機）で分けている乗員から見える違い（AFDS の ATT など）は、GE の機体を 570 に合わせる（RR は資料が無いので P&W と同じ：推定）。2026-10-27 に利用者がいったん P&W を 405（PW の改造貨物機）にすると決め、ND の向きと AFDS の G/S を 405 にしたが、同じ日に 109 に戻した。109 と 405 の違いの一覧は [EFFECTIVITY_405.md](EFFECTIVITY_405.md)（参考）。
- 「推定」と書いたものは、資料に値や記載が無いので決めた部分（全部の一覧は [PROGRESS.md](PROGRESS.md) の「推定で作った部分」）。
- 作り直した分野は、X-Plane での試験（Web API と FlyWithLua の記録）まで済ませている。残っている違いの多くは、まだ作り直していない分野のもの。

## 2. 分野ごとの違い

### 電源（ATA 24）：作り直し済み（1-1）

実機に合わせた点：バス単位のモデル（AC 1〜4、同期バス、SSB、transfer bus、standby、ground service・ground handling、DC 1〜4、バッテリー母線）、電源の切替（LH24 の表と FCOM）、GCB・BTB の許可、standby 電源、ELEC GEN OFF・ELEC AC BUS・ELEC BUS ISLN、DRIVE 灯と DRIVE DISC、ELCU の load shed（簡略）、バッテリーの表示と BAT DISCH、air mode。P5 の灯、EICAS、表示器と CDU の電源もモデルから。カスタム acf の ELEC synoptic（ISLN・DRIVE の枠、UTILITY と GALLEY を母線ごとの色で）と STAT のバッテリー値・CHG/DIS。autoland の母線の分離（ELEC-18、2026-10-30）：APP で multi-channel が arm すると FCC が分離を求め、BCU が発電機の数で構成 A〜E に BTB と DCIR を開く（LH24 p.244–247）。分離の間は ISLN 1〜3 の灯と ELEC BUS ISLN 1〜3 を出さず、カスタム acf の ELEC synoptic は「ELECTRICAL SYNOPTIC INHIBITED FOR AUTOLAND」だけ（FCOM p.789、p.802）。分離の完了（BUS ISOLATED）が LAND 3 の条件で、分離しなければ NO LAND 3（ATA22 p.192、p.384）。

残っている違い：
- 保護トリップ、3.5 秒の break power transfer、last source on が無い（ELEC-04）。故障の仕組みがまだ無い。
- 手動の SSB スイッチ・OPEN 灯、GEN FIELD MAN RESET・FIELD OFF 灯が無い（3D にも操作子が無い。ELEC-05・22）。
- 客室側の ground service switch が無い（ELEC-13）。
- autoland のバス分離：TRU の故障が無いので、構成を選ぶのは発電機だけ。分離は瞬時（実機は 4 秒以内）。4 秒で分離しなければ NO LAND 3 の、4 秒は推定。
- 故障で出る status（ELEC DRIVE、BAT CHARGER、ELEC TR UNIT、ELEC IDG VALVE）が無い（ELEC-23）。
- 外部電源は XP12 では X-Plane の GPU 電圧に依る（ELEC-17）。
- まだ X-Plane の bus 0 で電源を見る系統：機器冷却、IRS と無線、表示灯の輝度、客室灯、ヨーダンパー。
- 純正 acf の ELEC synoptic と STAT は前のまま（GALLEY は UTILITY と同じ色、STAT は X-Plane の値と固定の "DIS"）。freighter の galley 無し（570）は電源モデルにまだ無い。
- 推定：バッテリーの負荷電流と電圧の曲線、BAT DISCH までの 60 秒など。

### 空地判定（PSEU）：作り直し済み（1-2）

実機に合わせた点：主脚のトラックの傾きで左右とも接地したときに地上（片側だけなら空中）、pri・alt の 2 系統、前脚の圧縮。電源の air mode、脚レバーのロック、逆推力のロックアウト、燃料系はこれを使う。

残っている違い：
- autopilot、fms、計器、操縦系統、EEC、エンジン、油圧、脚（タイヤ圧）、manipulators、fdr、照明など 15 モジュールが、まだ X-Plane の「どれか 1 輪接地」（`onground_any`）を読む。各系統の作り直しで乗り換える。
- 推定：トラックの傾きは X-Plane の `eagle_claw_angle_deg`（胴体に対するトラックの角度）が 4° を超えたとき、前脚の圧縮は前輪の接地（X-Plane に傾きセンサーと strut の縮みが無い）。

### 乗員への警報（EICAS、警報音）：枠組みは作り直し済み（1-3）

実機に合わせた点：新しいメッセージはそのレベルの群の先頭（advisory は caution の下。2026-10-24 に直した）、CANC/RCL（メッセージごとの CANC 済みの印）、サイレン・ベル・beeper が警報モデルから鳴る（`.snd` の結線）、caution ごとの beeper、抑止（始動前、始動中、離陸、着陸）、メッセージ表のレベルと文言を FCOM に、ページ割り（カスタム acf は 10 ページまで）、0.1 秒ごとの更新、STATUS メッセージと STATUS cue。

残っている違い：
- 他のメッセージによる抑止と時間遅れは、系統ごとにまだ（各系統の作り直しで足す）。
- FCOM にあって表に無いメッセージが約 30 件（WARN-08。各系統で）。
- 離陸形態警報が「エンジン 2 と 3 の両方」を要求する（FCOM は 2 か 3）。着陸形態警報（CONFIG GEAR）は、着陸フラップ（フラップ 25 を含める）と「どれか 1 本のレバーが閉」（プラグインのレバーを 1 本ずつ）を操縦系統 4-1 段 3 で直したが、リセットの可否・脚上げ後の抑止などは無い（WARN-11・12。GND PROX GEAR OVRD での抑止は 5-1 段 4 で）。
- SPEEDBRAKES EXT の条件式（WARN-13）は操縦系統 4-1 段 3 で直した（空中の CONFIG SPOILERS も貨物機だけに）。>STAB GREENBAND が無い（WARN-14 の残り。グリーンバンドの 3 帯と CONFIG STAB の帯は操縦系統 4-1 段 2c で）。
- OVERSPEED を Vmo/Mmo でなくフラップ・脚の制限込みの Vmax で出す（WARN-15）。
- ALTITUDE ALERT が無い（WARN-16）。
- 失速警報（スティックシェーカー）は 5-2 段 3b で、今の Mach で必要な揚力が FCTM のシェーカー速度から作った境界を超えたときに出す（荷重倍数を含む。実機の SWMC の迎角の比べ方そのものではない：WARN-18 の残り）。
- GPWS の PULL UP・WINDSHEAR の master WARNING は 5-1 段 4 で作った（WARN-19）。
- PILOT RESPONSE、チャイムの論理、MAWEA の電源が無い（WARN-20〜22）。
- APU・貨物室・車輪格納部の火災のベルは、火災（3-4）で。
- 純正 acf のパネルは 2 ページまでしか描けない（PG も無い）。

### 油圧（ATA 29）：作り直し済み（1-4）

実機に合わせた点：EDP は圧力補償型、demand pump の AUTO（1400/1600 psi、タイマー、CUTOFF、系統 1・4 のフラップ）、ポンプの電源と抽気、AUX、火災スイッチ（SOV 閉・EDP 減圧・demand pump 起動）、舵面の系統の組の誤り 3 か所を修正、accumulator（系統 4 だけで充圧）、X-Plane の故障を書き換えない、P5 の灯、EICAS、作動油量（乱数をやめた）、リザーバの与圧と RSVR PRESS、STATUS、スタンドパイプ。カスタム acf の HYD synoptic（ポンプの記号を状態の色で、各系統と系統の組の不作動項目。P&W は THRUST REV つき）。

残っている違い：
- 系統の圧による制限：ステアリング（4-2 段 4：系統 1 の脚 DOWN 圧。HYD-12 は済）、脚（4-2 段 1：前脚・胴体脚は系統 1、翼脚は系統 4）、安定板トリム（4-1 段 2b：系統 2・3）、ヨーダンパー（4-1 段 4：上は系統 3、下は系統 2）は済。P&W の逆推力は、エンジン 2-3 で系統 n の圧が 1,000 psi 未満なら動かないようにした。
- ブレーキの効きは源（系統 4、1、2、accumulator）の圧で決まる（4-2 段 2。HYD-09 は済）。
- 油温に燃料の熱交換が無い（HYD-17）。
- 純正 acf の HYD synoptic は前のまま（色の付かない記号、組の中身が合わない不作動項目の絵）。
- FLT CONTROL HYD POWER（系統ごとの遮断弁）が無い（HYD-22）。
- 推定：舵面が動く圧 1000 psi、漏れ量、圧の立ち上がり、油温の上がり方、synoptic の不作動項目の組（1+2+4 の BRAKES）と RR の THRUST REV など。

### 空圧（ATA 36）：作り直し済み（1-5）

- 空中開始では FMS が F/D L・A/T・ALT HOLD・CMD L を入れる（試験のための初期化。段 1a から ALT HOLD は F/D の既定のモードの 1 秒後、飛行の開始のたびに、何度走っても同じ）。前は機体の読み込み方で動きが変わった。

### オートスロットル・推力管理：作り直し中（6-4：FMC の段 9f1 のモードの論理と engage・disconnect、段 9f2 の制御則と servo、段 9f3 の interlock）

- 実機に合わせた点（段 9f3、2026-10-31）：A/T の engage に電源の条件（servo の F/O transfer bus と DC bus 1 か 2：ATA34_2 p.450）を足した（失えば外れて >AUTOTHROT DISC）。VNAV の降下で FMC が A/T に速さを求めるのに A/T が engage していなければ THRUST REQUIRED（FCOM p.1434。前は出す処理が無かった：ATHR-19）。推定：DC はどちらか 1 本で足りること。
- 実機に合わせた点（FMC の段 9d2、2026-10-31）：VNAV の THR（早期降下と cruise descent）はレバーを FMC の V/S（約 1,250 fpm）へ動かす。見るのは目標の速さでのエネルギーの率（慣性の V/S と目標の IAS か Mach の変化から、速さを目標に保てば出る V/S）で、効きは FLCH の 1/2、慣性の V/S とエネルギーの率がその率の 100 fpm 以内で速さが目標の 5 kt 以内に 5 秒とどまれば HOLD、aft stop か手の 8° でも HOLD（どれも推定。ATA34_2 p.647：VNAV の推力は FMC の基準推力へ。FMSPG p.3.5-5：その率に達すると THR HOLD。V/S で見ると、降下の速さへ減速しながら上昇する間にレバーを aft stop まで絞り、アイドルで −2,600 fpm になった。計器の V/S が率を一度越えただけで HOLD にすると、X-Plane のエンジンと速さの遅れで率を大きく越え、目標の速さでは水平か上昇になった。率に達した瞬間に HOLD にすると、降下の途中で押した時にピッチが速さを取る間に V/S が率を一瞬で通り、巡航の推力のまま HOLD になって上昇に戻った。FMC の段階が変われば THR から。前は VNAV が THR を求めることが無く、THR の則は FLCH の 125 秒の則と G/A だけ）。VNAV の水平（VNAV ALT・PTH）の後に降下を続けると IDLE からやり直す（前は IDLE の HOLD の掛け金が残り、すぐ HOLD）。

- 実機に合わせた点（段 9f2、2026-10-31）：A/T の制御則と servo を A/T のモデルに移した（前は EEC がモードごとに 1 フレームずつ刻み、速さがフレームに依った）。各則がレバーの速さを出し、servo が 10°/s（flare retard は 5°/s）までで積分する（ATA34_2 p.648）。FLCH と G/A の 1 回目は THR（V/S の則：FLCH は 125 秒で MCP 高度、G/A は 2,000 fpm、上昇で V/S が多くても推力を減らさない：p.646、p.670、p.674。前は THR を出さず THR REF で上昇推力まで）、G/A の 2 回目は THR REF。FLCH の降下はレバーが後ろの stop で HOLD、FLCH でレバーが指令から 8° 離れると HOLD（p.648）。THR REF は推力の基準へ、限界の速さを越えない（p.672）。SPD は増が速く減が遅い（FCTM p.43）、thrust limit と速度の保護（Vmax − 5、最小 + 5：FCOM p.675）。操縦者の override：A/T の間でも手のレバー（ハードウェアか 3D）が動けばそれに従い、止まって 1 秒で指令に戻る（ATHR-09）。VNAV の降下で目標より 15 kt（速度の遷移の下で 10 kt）遅いと A/T は SPD（FCOM p.1259）。推定：ゲイン、手が止まってから戻るまでの 1 秒、戻りの 5 kt。

- 実機に合わせた点（段 9f1、2026-10-31）：A/T の状態とモードを 1 つのモデル（`B747.70.at_model.lua`）が持つ（前は 7 か所から書かれ、FMA は毎フレームの if の連鎖）。A/T はモードで engage する：VNAV・FLCH の engage、TO/GA（地上は 50 kt 未満・フラップ UP でない・TO の limit、空中はフラップ UP でないか G/S）、SPD・THR スイッチ（400 ft の上、ピッチのモードの条件）、VNAV・FLCH の間の ARM の ON（FCOM p.641–642、p.656）。前は V/S・ALT・G/S や A/P の解除の後に勝手に active になり、TO/GA は ARM OFF でも active にした。TO の THR REF は 65 kt で HOLD、VNAV の engage か別のモードまで HOLD（前は 50 ft で THR REF に戻った）。50 kt までに押さなければ 400 ft まで engage しない。VNAV・FLCH から ALT・V/S・G/S で SPD、T/O・G/A からの水平では変えない（FCOM p.673）。VNAV の IDLE はレバーが後ろの stop に着くと HOLD（ATA34_2 p.666）。>AUTOTHROT DISC は engage から外れたときだけ（ARM OFF、disconnect、interlock）、地上の reverse では出さない、disconnect の 2 回目か次の engage で消える（FCOM p.657、p.677。前は A/T の fail そのもので、reverse の着陸のたび、外れていても disconnect を押すと出た）。SPD の 25 ft の IDLE は autoland の flare retard だけ（ATHR-12。前は手の着陸でも）。推定：運転中のエンジンの判定（N1 15 %）、地上で 30 kt 未満で 50 kt の禁止を解くこと。

- VNAV の間の A/T のモードは 2026-10-31（FMC の段 9c）から FMC の要求（上昇 THR REF、巡航 SPD、降下 IDLE、経路の下と浅い区間は SPD、水平は SPD）で、VNAV の engage の時に A/T ARM なら active になる（FCOM p.645）。推力の基準（TO・CLB・CRZ）は FMC の段階から（離陸の TO は電波高度 1,000 ft まで：推定）。A/T そのもの（モードの状態機械、servo、HOLD、THR）は前のまま（段 9f で作り直す）。
- 推力制限のモードが「飛行段階」の値だけから作られ、それを多くの操作が書く（ATHR-01）。
- assumed temperature が推力に効かない（ATHR-03）。CLB の基準が定格でなく固定の上昇率から（ATHR-04）。

## 3. X-Plane の上で作ることによる違い

- 推力・燃料流量・空力は X-Plane の計算。燃費は acf の SFC で決まる（2026-10-30 に FCOM の長距離巡航と待機、ICAO の離陸に合わせた：notes/AERO.md §3.9）。
- カスタム acf の飛び方を FCOM PI.10.38–10.40（速度計異常の姿勢と推力の表）と比べている（2026-10-29〜、notes/AERO.md）。主翼の取り付け角を 1.0° 下げて、クリーンの姿勢は FCOM と ±0.3° に入った（前は約 1.0° 機首が低かった。巡航は +0.4°）。ナセルと翼胴フェアリングの抵抗を下げた（形状抵抗は約 0.017、揚抗比 14〜16）。2026-10-30 にエンジンを合わせた：アイドル（290 kt の降下は FCOM と 3 % 以内。前は 1.3〜1.4 倍急）、P&W の表示の EPR（離陸・最大上昇・長距離巡航の EPR と上昇率が FCOM と合う）、燃料流量（長距離巡航と待機が 3 % 以内）、地上滑走（転がり抵抗）。残っている違い：
  - フラップの揚力：X-Plane は 20° の先で伸びない（FCOM は 30° まで伸びる）。係数・最大角・型・翼弦比・翼型では直らないので、2026-10-30 に利用者が認めた補正で、FCU が X-Plane の翼に渡す角度を detent ごとの表にした（5 → 3.2°、10 → 8.2°、20 → 15.1°、25 → 18.6°、30 → 30°。acf のフラップの揚力の係数 1.62・最後の detent 75°：notes/AERO.md §3.12）。迎角は FCOM と 5〜30 で 0.4° 以内（前は 20 で 1.7°・25 で 0.7° 小さく、30 で 0.7° 大きかった）。3D のフラップと EICAS は実際の角度。150 kt・フラップ 30 の進入のピッチは約 2.9°（前は 3.4°）。
  - ラダー：ペダルで方位を保つ試験から、X-Plane の VMCG は約 125〜127 kt（推定。FCOM 121 kt）でほぼ合う。片発のラダートリムは 4 分の 1 で操縦輪が水平になる（FCTM p.55 の手順どおりにはなる）。
  - FCTM の典型の降下率（重量の記載なし）より、340 kt で 17 %、250 kt で 12 % 急（FCOM の 290 kt に合わせたので合わせ込まない）。
  - A/T の上昇推力は決まった上昇率に要る推力（ATHR-04）。
  - 離陸の直後（低速）は A/P の内側のループが遅れてから行き過ぎ、速度が V2 + 30 を少し超えることがある（推力が離陸の定格どおりに増えたため。段 3c で直す）。
- カスタム acf の失速の速さを FCTM の失速速度に合わせた（2026-10-25、利用者の承認：主翼の翼型の失速を早め、前縁スラットの効きを下げた。ACF_DIFF.md §5、notes/FCTM.md §1.14）。前は約 270 t・10,000 ft でクリーンの 1 g 失速が約 153 kt（FCTM 173 kt）、フラップ 10・20・30 は昇降舵いっぱいでも失速しなかった。後の FCTM との差は UP −2、10 +6、20 −5、30 +4 kt（測り直すと ±3 kt ほどばらつく）。X-Plane の後縁フラップの揚力の増え方が実機と違う（角度とともに頭打ち）ので、フラップごとに数 kt の差が残る。実際の失速から段 3b のシェーカー（FCTM のシェーカー速度）までの余裕は、10 と 30 で約 2 kt（実機は 6〜7 kt）、20 で約 10 kt、UP で約 23 kt。フラップの揚力の補正（2026-10-30、上）の後は、10・20・30 が FCTM から 1 kt 以内（10 −0.3、20 +0.8、30 +0.7 kt）。
- 脚・ブレーキ・オートブレーキ・ブレーキ温度は機体側で作った（4-2 段 1〜3・5）。X-Plane へは脚の位置・ブレーキの比・パーキングブレーキの比を書き、制動・タイヤ・ABS の計算は X-Plane。ステアリング（段 4）も機体側で角度を決め、X-Plane へは前輪と胴体脚の角度を書く。逆推力は、動ける条件は作り直したが、展開・格納の動きと推力は X-Plane の計算。
- 与圧は X-Plane の与圧に値を書いている（空調 3-1 まで）。
- X-Plane が 20 fps を切るとシムの時刻は 1 フレーム 0.05 秒しか進まない。AFDS のピッチ・ロール、A/T のサーボ、SRM のトリム、EEC の推力の制御もそれに合わせて 1 フレーム 0.05 秒までしか進めない（2026-10-31。前は XTLua の実時間の刻みで、長いフレームで何秒分も一度に進み、s145 で F/D のピッチの指令が −2.5°、スタビライザーが一度に動いた）。
- 経路と ND の経路線は X-Plane 標準の FMS（FMC の作り直しまで）。
- X-Plane 側の制約（試験で見つけたもの）：機体を読み直さずにフライトを始めると前のフライトの状態が残る系統がある。XP12 の外部電源は X-Plane の GPU 電圧に従う。X-Plane の抽気のモードと isolation valve は連動する。Web API の長さ 0 のコマンドは離す操作が届かない。
