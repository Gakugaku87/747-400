# 実機との違い（DIFFERENCES）

Sparky744（この作業ツリーの機体）が、実機の 747-400 とどこで違うかを、全分野についてまとめたもの。2026-10-24 の時点（`overhaul`、火災防護まで）。

- 元の調査は [GAP_ANALYSIS.md](GAP_ANALYSIS.md)（作り直し前のコードと資料の読み比べ、550 件）。ここでは、その後の作り直しで直った点を反映し、残っている違いを分野ごとに短く書いた。各項目の括弧は GAP の ID で、詳しい内容と出典は GAP_ANALYSIS.md と `notes/` にある。
- 基準の機体は FCOM の 109（旅客機、PW4056）。405（PW の改造貨物機）と 570（GE の貨物機）の違いは notes に書いてある。RR には資料が無い。
- 「推定」と書いたものは、資料に値や記載が無いので決めた部分（全部の一覧は [PROGRESS.md](PROGRESS.md) の「推定で作った部分」）。
- 作り直した分野は、X-Plane での試験（Web API と FlyWithLua の記録）まで済ませている。残っている違いの多くは、まだ作り直していない分野のもの。

## 2. 分野ごとの違い

### 電源（ATA 24）：作り直し済み（1-1）

実機に合わせた点：バス単位のモデル（AC 1〜4、同期バス、SSB、transfer bus、standby、ground service・ground handling、DC 1〜4、バッテリー母線）、電源の切替（LH24 の表と FCOM）、GCB・BTB の許可、standby 電源、ELEC GEN OFF・ELEC AC BUS・ELEC BUS ISLN、DRIVE 灯と DRIVE DISC、ELCU の load shed（簡略）、バッテリーの表示と BAT DISCH、air mode。P5 の灯、EICAS、表示器と CDU の電源もモデルから。カスタム acf の ELEC synoptic（ISLN・DRIVE の枠、UTILITY と GALLEY を母線ごとの色で）と STAT のバッテリー値・CHG/DIS。

残っている違い：
- 保護トリップ、3.5 秒の break power transfer、last source on が無い（ELEC-04）。故障の仕組みがまだ無い。
- 手動の SSB スイッチ・OPEN 灯、GEN FIELD MAN RESET・FIELD OFF 灯が無い（3D にも操作子が無い。ELEC-05・22）。
- 客室側の ground service switch が無い（ELEC-13）。
- autoland のバス分離が無い（ELEC-18。AFDS の作り直しで）。
- 故障で出る status（ELEC DRIVE、BAT CHARGER、ELEC TR UNIT、ELEC IDG VALVE）が無い（ELEC-23）。
- 外部電源は XP12 では X-Plane の GPU 電圧に依る（ELEC-17）。
- まだ X-Plane の bus 0 で電源を見る系統：機器冷却、IRS と無線、表示灯の輝度、客室灯、ヨーダンパー。
- 純正 acf の ELEC synoptic と STAT は前のまま（GALLEY は UTILITY と同じ色、STAT は X-Plane の値と固定の "DIS"）。freighter の galley 無し（570）は電源モデルにまだ無い。
- 推定：バッテリーの負荷電流と電圧の曲線、BAT DISCH までの 60 秒など。

### 空地判定（PSEU）：作り直し済み（1-2）

実機に合わせた点：主脚のトラックの傾きで左右とも接地したときに地上（片側だけなら空中）、pri・alt の 2 系統、前脚の圧縮。電源の air mode、脚レバーのロック、逆推力のロックアウト、燃料系はこれを使う。

残っている違い：
- autopilot、fms、計器、操縦系統、EEC、エンジン、油圧、オートブレーキ、manipulators、fdr、照明など 15 モジュールが、まだ X-Plane の「どれか 1 輪接地」（`onground_any`）を読む。各系統の作り直しで乗り換える。
- 推定：トラックの傾きは X-Plane の `eagle_claw_angle_deg`（胴体に対するトラックの角度）が 4° を超えたとき、前脚の圧縮は前輪の接地（X-Plane に傾きセンサーと strut の縮みが無い）。

### 乗員への警報（EICAS、警報音）：枠組みは作り直し済み（1-3）

実機に合わせた点：新しいメッセージはそのレベルの群の先頭（advisory は caution の下。2026-10-24 に直した）、CANC/RCL（メッセージごとの CANC 済みの印）、サイレン・ベル・beeper が警報モデルから鳴る（`.snd` の結線）、caution ごとの beeper、抑止（始動前、始動中、離陸、着陸）、メッセージ表のレベルと文言を FCOM に、ページ割り（カスタム acf は 10 ページまで）、0.1 秒ごとの更新、STATUS メッセージと STATUS cue。

残っている違い：
- 他のメッセージによる抑止と時間遅れは、系統ごとにまだ（各系統の作り直しで足す）。
- FCOM にあって表に無いメッセージが約 30 件（WARN-08。各系統で）。
- 離陸形態警報が「エンジン 2 と 3 の両方」を要求する（FCOM は 2 か 3）。着陸形態警報（CONFIG GEAR）のレバーの判定も粗い（WARN-11・12）。
- SPEEDBRAKES EXT の条件式の誤り（WARN-13）。>STAB GREENBAND が無い（WARN-14 の残り。グリーンバンドの 3 帯と CONFIG STAB の帯は操縦系統 4-1 段 2c で）。
- OVERSPEED を Vmo/Mmo でなくフラップ・脚の制限込みの Vmax で出す（WARN-15）。
- ALTITUDE ALERT が無い（WARN-16）。
- 失速警報が AOA でなく速度の表で出る（WARN-18）。
- GPWS の PULL UP・WINDSHEAR で master WARNING が点かない（WARN-19）。
- PILOT RESPONSE、チャイムの論理、MAWEA の電源が無い（WARN-20〜22）。
- APU・貨物室・車輪格納部の火災のベルは、火災（3-4）で。
- 純正 acf のパネルは 2 ページまでしか描けない（PG も無い）。

### 油圧（ATA 29）：作り直し済み（1-4）

実機に合わせた点：EDP は圧力補償型、demand pump の AUTO（1400/1600 psi、タイマー、CUTOFF、系統 1・4 のフラップ）、ポンプの電源と抽気、AUX、火災スイッチ（SOV 閉・EDP 減圧・demand pump 起動）、舵面の系統の組の誤り 3 か所を修正、accumulator（系統 4 だけで充圧）、X-Plane の故障を書き換えない、P5 の灯、EICAS、作動油量（乱数をやめた）、リザーバの与圧と RSVR PRESS、STATUS、スタンドパイプ。カスタム acf の HYD synoptic（ポンプの記号を状態の色で、各系統と系統の組の不作動項目。P&W は THRUST REV つき）。

残っている違い：
- 脚・ステアリング・安定板トリム・ヨーダンパーが、4 系統の圧で止まらない（HYD-11・12。それぞれの作り直しで、モデルの負荷の表を使う）。P&W の逆推力は、エンジン 2-3 で系統 n の圧が 1,000 psi 未満なら動かないようにした。
- ブレーキの効きが油圧源で制限されない（源の選択と >BRAKE SOURCE は済。HYD-09 の残り、脚 4-2 で）。
- 油温に燃料の熱交換が無い（HYD-17）。
- 純正 acf の HYD synoptic は前のまま（色の付かない記号、組の中身が合わない不作動項目の絵）。
- FLT CONTROL HYD POWER（系統ごとの遮断弁）が無い（HYD-22）。
- 推定：舵面が動く圧 1000 psi、漏れ量、圧の立ち上がり、油温の上がり方、synoptic の不作動項目の組（1+2+4 の BRAKES）と RR の THRUST REV など。

### 空圧（ATA 36）：作り直し済み（1-5）

実機に合わせた点：需要と供給からのダクト圧（区画ごと）、エンジンの HPSOV・PRV・PRSOV、逆流防止、始動弁の条件（クロスブリードは供給側 70 % N2）、過熱ラッチとスイッチでのリセット、ISLN 弁の移動時間と VALVE 灯・BLEED ISLN（10 秒の不一致）、APU 弁（RUNNING ＋ 2 秒、OFF で閉）、ISLN の電源、STATUS の BLEED ASCTU。

残っている違い：
- 過熱・過圧・ダクトリークの故障がつながっていない（BLEED n、BLEED HP ENG、BLD DUCT LEAK。PNEU-03。X-Plane に相当する故障が無い）。
- 地上空気（エアカート）をつなぐ操作が無い（PNEU-07）。
- スターターの回り方：X-Plane のエアスターターはダクト圧で回る（3-1 で与圧を上書きしたので、X-Plane のダクトの空気にこちらのダクト圧を書いている）。圧と回り方の関係は X-Plane のもので、資料に無い（PNEU-08）。
- ECS synoptic の弁の記号に、PRSOV の琥珀の OFF と移動中の形が無い（PNEU-11 の残り。パネルの絵が無い）。主 EICAS のダクト圧の表示条件（PNEU-09）と synoptic の流れの線は 3-1 で直した。
- GE の逆推力のとき、HPSOV と PRV が BLEED スイッチ OFF でも開く動きが無い（PNEU-12）。逆推力の側は、エンジン 2-3 でそのエンジンが運転中なら動くようにしたが、過熱や始動弁で PRV が閉じていても動く。
- EEC の抽気補正は、運転中のパックの数と防氷弁で決め、実際の抽気源（APU からパックへ、エンジン抽気 OFF）を見ない（PNEU-13 の残り）。抽気による推力の損失は、エンジンが出す抽気の量からの推定（X-Plane の吸気温度の上昇として、パック 1 台分で 1 ℃）。
- 推定：流量（high flow のパック 1 台＝1 の単位）、ダクト圧の下がり方、弁の時間など、式と値の多く。

### APU（ATA 49）：作り直し済み（2-1）

実機に合わせた点：1 つの状態機械、START→ON で始動を保持、ドア全開で starter、60 秒の cooldown（抽気弁と発電機は無負荷）、自動停止（火災、燃料切れ、始動の失敗）と fault の保持、APU・APU DOOR・APU RUNNING を FCOM の条件で、STATUS の N2・油量。

残っている違い：
- 始動電源と始動回数の制限が無い（APU-09）。
- 空中の運用範囲（高度）が無い（APU-10。資料が自動停止を書いていない）。
- 油の消費と RF/LO が無い（APU-02）。抽気ダクト過熱の停止は入力が無い。
- エンジン始動時の増風要求が無い（APU-12）。
- 回転と EGT は X-Plane の APU のまま。
- 推定：ドアの開く時間 12 秒、APU DOOR の 20 秒、始動の打ち切り 120 秒、N2 = N1 × 0.926 など。

### 燃料（ATA 28）：作り直し済み（2-2）

実機に合わせた点：
- タンク・ポンプ・弁の表、圧力の順位（CWT ポンプ 2 台 ＞ O/J 2・3 ＞ 主ポンプ。CWT ポンプ 1 台は主ポンプ 2 台に勝てない）。
- クロスフィードのマニフォールド（開いた xfeed を通して他の主タンクからも）と吸引供給（ポンプが止まってもエンジンは止まらず、FUEL PRESS ENG）。SP.12 の均衡手順が成り立つ。
- xfeed 2・3 の自動閉（地上でフラップ 10〜20 に 40 秒、空中はフラップがその範囲を出るまで保持）、O/J 2・3 の起動条件、予備タンクの移送（主 2 か 3 が 18,200 kg で 4 弁とも、空中だけ）、CWT のスカベンジ（ジェットポンプ）、水平安定板タンクの移送（109）、shared flow。
- ジェティソン（FTR で停止、主 2・3 の均衡、主 1・4 の移送、終了後の FUEL OVRD、時間の推定と 90 秒後の更新）。
- 弁はバスごとの電源で 4 秒かけて動き、電源が無いとその位置に留まる。不一致のメッセージ（FUEL X FEED、FUEL RES XFR、>JETT NOZZLE）。
- 頭上の灯（主ポンプの PRESS は低圧ならいつでも、CTR はスイッチ ON のとき、O/J と STAB は論理が動かしているとき、X FEED と NOZZLE の VALVE 灯）。EICAS の閾値を FCOM に。
- APU の DC 燃料ポンプと APU FUEL、spar valve が火災スイッチで閉じる、タンク容量を acf から、FUEL USED はエンジンの流量だけ。

残っている違い：
- 消費は X-Plane の燃料流量で、acf の燃費（SFC）がそのまま効く。カスタム acf の SFC は巡航の測定で約 25 % 少なかったので、純正と同じ値にした（FL350・269 t で 1 発 2,134 kg/h。FCOM PI.11.2 の長距離巡航は 260 t で 2,211、280 t で 2,378 kg/h）。離陸と上昇の燃料流量はまだ資料と比べていない（エンジン 2-3 で）。
- FMC の側：TOTALIZER と CALCULATED が同じ、FUEL DISAGREE が無い、FUEL USED がエンジン始動で消えない（FUEL-13。FMC で）。
- ポンプ・弁の故障が無い（FUEL-15）。FUEL TEMP SYS、>FUEL JETT A/B は無い。
- 燃料温度は TAT への一次遅れで、根拠が無い（FUEL-20）。
- 地上で 100 t を超えて始めたときの固定の配分と給油の順序は前のコードのまま（資料で確かめられない。FUEL-21）。
- synoptic：ポンプの琥珀はタンクが 10 kg 未満のとき、主タンクの琥珀は 900 kg 未満だけ（パネルの条件）、FTR は LBS 表示でも kg（FUEL-24）。
- 貨物機の設定では水平安定板タンクの論理を止めるが、タンク 7 の燃料と synoptic の絵は残る。
- エンジン運転中の開始では CTR ポンプのスイッチが ON になるので、CWT が空だと FUEL PRESS CTR が出る（開始時のスイッチの設定は manipulators の側）。
- 地上でポンプのスイッチが OFF のときに FUEL PUMP のメッセージを出すかは、資料に記載が無い（今は低圧なので出す）。
- 推定：重力移送・安定板タンクのポンプ・ジェティソンの流量、APU の消費 150 kg/h、ポンプの AC バスの割り当て、フラップの離陸範囲の換算、安定板ポンプが低圧で止まるまで 30 秒。

### エンジン（ATA 71〜80）：一部（2-3 段 1・段 2、段 3 の一部）

実機に合わせた点（段 1）：エンジンごとの始動の状態機械（手動始動、autostart の燃料投入・light-off・hot・hung の検出・地上の再試行と中止・空中は中止しない）、50 % N2 の cutout、点火の条件（START、CON、フラップ、NAI、flameout）と AUTO・STBY IGNITION と電源、エンジン燃料弁（RUN と火災スイッチ）、START VLV・STARTER CUTOUT・FUEL VLV・ENG AUTOSTART・>AUTOSTART OFF・ENG IGNITION・ENG FAIL（caution）・>ENG SHUTDOWN。

実機に合わせた点（段 2）：EEC の最大定格（Max N1・EPR）を FCOM PI の表（着陸復行・最大上昇）と抽気の補正から出し、全開のときの定格を高度と速度で選ぶ（CF6 の論理）。レバーはアイドル端から最大定格までの指令で、全開で最大定格、上昇中にレバーを止めれば指令の N1・EPR は一定。上の EICAS の最大線は EEC の定格。推力の制御は実際の N1・EPR を指令に合わせる（定常で EPR ±0.002・N1 ±0.2 %、全開でも最大定格を超えない）。オーバースピード保護（N1・N2 を赤線の手前で止める）と >ENG RPM LIM（GE は N2、P&W は N1 か N2）。空中で止まったエンジンの N2（風車回転）を 0 にしない。approach idle（空中で防氷・着陸フラップ・405 と 570 の CON、GE の逆推力）と、条件が終わって 5 秒・接地 5 秒後の minimum idle。ALTN（EEC MODE スイッチ）：最大定格で頭打ちしない指令、ENG EEC MODE・>ENG LIM PROT、A/T の切断と使える条件（GE は 4 基とも代替、P&W は全部 normal）。

実機に合わせた点（段 3 の一部）：EGT の白・琥珀・赤を型式ごとの限界で決め、TO/GA スイッチを押してから 5 分（P&W はエンジンが止まれば 10 分）は琥珀にしない。始動限界の赤線は CUTOFF と始動の途中で出し、その間は始動限界で赤。逆推力：P&W は関係する油圧系統（エンジン n は系統 n）、GE はそのエンジンの運転（抽気）が無いと動かず、地上でだけ動く（逆推力 1・4 は PSEU の primary、2・3 は alternate の継電器）。動けない逆推力は今の位置のまま（展開していれば展開のまま）。ENG n REVERSER は、乗員が逆推力を求めているのに格納のまま、または逆推力でないのに展開のままが 2 秒続いたとき（前は X-Plane の故障だけ）。オイル：油圧は赤線の下で赤、ただしエンジンが CUTOFF と始動中は白のまま（前は CUTOFF でも赤）。GE の赤線は N2 で 10〜35 psi。ENG n OIL PRESS を足した（GE は低圧スイッチの 10/15 psid）。油量はエンジンごとの値（前は全エンジンが 1 番の故障の比）で、GE は US quart。振動は音源ごとの値から一番大きいもの。小さな誤りの修正：二次エンジン表示は空中で FUEL CONTROL を CUTOFF にしたときだけ出る（前は地上でも RUN でも）。燃料投入の印は火災スイッチを引くと消える。地上の始動はどの状態からも約 1 分（前はほかのエンジンが回っていると 3 倍速く、1 番エンジンだけ速かった）。FMC で選べる CF6-80C2-B1F1 と RB211-524H8T が自分の推力になる。超過の赤い枠：N1・EGT・N2・N3 の数字の枠は、限界に達すると赤になり、戻っても赤のまま残り、EICAS の CANC で白、RCL で赤に戻る。CF6 の N2 は赤線の上が 20 秒を超えると赤のまま。P&W の EPR は最大 EPR に届くと帯が赤（数字は白）。前はパネルの固定の値で、P&W の N1 の枠は X-Plane の N1、EGT の枠は X-Plane の EGT（尺度が違う）で赤くなっていた。パネルのオイルと振動：油圧の赤い数字（前は 10 psi 未満でだけ出た）、GE の油圧の琥珀、油温の数字の琥珀は 160 ℃ から（前は 150 ℃ からで白と重なった）、油量のマゼンタ、振動の音源の文字（N1・N2・FAN・LPT。前は BB だけ）。

残っている違い：

- 最大連続の定格（高度・速度・TAT の表）が無く、その範囲は最大上昇の値。離陸の定格は着陸復行の表で代用（通常モードの離陸の表が FCOM に無い）。P&W の EEC の論理は資料に無く CF6 と同じとした。RR は前の推力の論理のまま（資料が無い）。
- 推力の制御は X-Plane のスロットルを燃料の計量とみなした作りで、加速・減速の速さ（P&W 0.15 EPR/秒、GE は上げ 15・下げ 5 %N1/秒）とゲインは推定。X-Plane のエンジンが指令に届かないとき（GE の空中の高い定格など）は、前の仕組みで X-Plane の最大推力を少しずつ足す（ENG-03）。P&W の赤線（111.4 %）は資料に無く、表示が赤くなる値（ENG-03・04）。
- ALTN は手動だけ（EEC の故障と自動の移行が無い）。P&W の制御量は EPR のまま（実機は N1 に替わる）。代替モードの指令の上限は推定（ENG-05）。
- >ENG SHUTDOWN で master CAUTION の灯を点けない扱いがまだ（ENG-09）。シムの AUTOSTART スイッチは 1 個（109 は 4 個）。PW の始動の値（燃料投入の N2、EGT の限界）は資料に無く推定。
- X-Plane のアイドルは全エンジンで 1 つなので、1 基だけ approach idle の条件でも全部 approach idle になる。LOW IDLE・IDLE DISAGREE はアイドルの故障が無いので出ない（ENG-06・07）。
- partial・compact 形式と exceedance cue が無い（ENG-22。5-2 の EICAS の形式で）。空中始動の範囲（X-BLD）は、範囲の表が手元の資料に無く作れない（ENG-24）。赤い枠は新しいフライトで消える（実機は整備で消す）。P&W・RR の N1・N2・N3 の赤線は資料に無く前の値。
- オイルと振動の値は作った値（X-Plane の油圧・油温にエンジンごとの差、油量はタンクとエンジンの量、振動は回転の 2 乗。推定）。GE の油圧の値と目盛りは P&W 向けのまま（X-Plane の 150 psi 前後、針は 70〜300 psi）。GE の油圧の針の目盛りと動く赤線・琥珀の帯（CF6 の値は資料に無い）、振動の high band（CF6 は 4.0）がパネルに無い。P&W・RR の油圧・油温の限界は資料に無く前の値。ENG n OIL FILT は X-Plane に相当する故障が無く出ない（ENG-25〜29）。
- 逆推力の動き（展開・格納の速さ）と逆推力の推力は X-Plane の計算で、全開でも N1 68 % くらいと実機より弱い。CF6 の EEC の逆推力の指令（レバー角に比例、最大定格の 90 % まで。ATA70_80 p.206）、auto-restow、REV INTERLOCK・REV POS（整備用の status）が無い。RR の逆推力の動力は資料が無く P&W と同じ（油圧）とした。ENG n REVERSER の 2 秒と、動けない逆推力を展開のまま保つ境目は推定（ENG-31）。
- P&W・RR の EGT の限界は資料に無く前の値。P&W の EGT の枠は赤の絵が無く、赤になると枠が消える。始動限界の線が消えるのは始動がアイドルで落ち着いたとき（FCOM は「所定の N2」とだけ書く）（ENG-20）。
- 表示の値は推力からの回帰式と比例換算（ENG-33）。EGT は離陸推力でも 300 ℃ 前後と低く、通常の運航では琥珀・赤にならない。GE の N1 表示は空中でレバーをアイドルから出す瞬間に下がる、P&W の EPR 表示はフラップが出ていると最大定格で頭打ち、P&W の N2 表示は整数（PROGRESS.md の「気づいたこと」）。スターターはダクト圧に依らず回る（ENG-38）。
- 試験で見つけたこと：始動中の燃料流量が負（燃料系では 0 として扱う）。空中の始動は地上より速く終わる（X-Plane のスプール時間は全エンジンで 1 つで、空中は推力の制御のため 5 秒のまま。ENG-35）。燃料投入の印の位置（N2 の目盛りの上）は固定の絵（ENG-37）。

### 空調・与圧・機器冷却（ATA 21）：作り直し済み（3-1）

実機に合わせた点：
- パック：弁（選択器、12 psi、貨物室火災 ARM でパック 3、リリーフ弁でパック 2）、normal と high flow（地上・上昇・降下は high、cruise clamp で normal、パックが 3 基未満・ファン故障・HI FLOW・リリーフ・貨物室火災で high、スケジュールの切替は 15 秒ずつ）、再循環ファン（地上・上昇・降下は上の 2 基、巡航は 4 基、上のファンが故障すると下のファン）、PTC A/B（NORM は便ごとに交代、TRIM AIR off で A、電源）、トリップと PACK RST・SYS FAULT 灯、PACK n・PACK CONTROL・memo。EEC は運転中のパック数で推力を補正する（前は選択器の値の合計）。
- 与圧：X-Plane の与圧を止め、客室の圧をパックの空気と外流弁・漏れ・リリーフ弁の流れの収支で計算する。CPC A/B（NORM は着陸ごとに交代、電源投入で A、2 秒の電源断・機体が水平で 2,000 fpm・ΔP 9.07 psi で他方が引き継ぐ）。モード：ground（外流弁全開）、65 kt で takeoff（場の高度 −50 ft）、climb（FMC あり 600 sea-level fpm 以下・なし 1,000 fpm 以下で巡航の客室高度へ）、cruise（FMC 巡航高度の 100 ft 以内か 45 秒の水平。客室を保つ）、descent（1,000 ft 降下。FMC ありは機体の降下に合わせて、なしは 300 fpm で着陸高度の 50 ft 下へ）、降下中の 2 分の水平、着陸後の減圧（500 fpm、1 分後 2,000 fpm）。
- 着陸高度：AUTO は FMC の出発地の標高、出発地から 400 NM・経路の半分・巡航・降下で目的地の標高（X-Plane の空港の一覧から）。FMC に無ければ 2,000 ft と LANDING ALT。MAN はノブで 50 ft 刻み、−1,000〜14,000 ft。機長の高度計の規正値で補正する。
- 客室高度リミッタ（自動のときだけ、11,000 ft で全閉、750 ft 下で解除）、手動の弁（片側ずつ、DC モーター、OPEN/CLOSE を押している間）、正圧リリーフ 9.25 psid（パック 2 停止、PRESS RELIEF）、負圧リリーフ、X-Plane の減圧の故障。
- メッセージ：CABIN ALTITUDE、CABIN ALT AUTO（両 CPC 故障か両方 MAN）、OUTFLOW VLV L・R、LANDING ALT、PRESS RELIEF、STATUS の CABIN ALT AUTO A・B、OUTFLOW VLV L・R、UPR・LWR PRESS RELIEF、CPCS AIR/GND。data block の表示条件に負の ΔP と LANDING ALT などを足した。カスタム acf の data block は、LDG ALT の数字を両 CPC 故障か両方 MAN で消し（AUTO・MAN の字は残る）、客室高度の赤い数字を 5 桁で出す（前は 4 桁で、10,000 ft 以上の先頭の桁が欠けた）。外流弁の計器は弁の位置（前は客室の昇降率から作っていた）。
- 機器冷却：NORM・STBY・OVRD の構成（地上は外気 45°F で機外か前方貨物室へ、各翼 1 基の運転で flight 構成、STBY は ground exhaust を閉）、ファン故障の closed loop と OVRD 30 秒のリセット、OVRD は差圧で客室の空気を機外へ（与圧に効く）、差圧が無いまま 55 秒で EQUIP COOLING（地上の OVRD でも出る）、貨物室火災 ARM で OVRD の構成。エンジン運転中の開始で TRIM AIR・RECIRC ON、EQUIP COOLING NORM。
- 温度制御：7 ゾーン（F/D、U/D、A〜E）の target（PASS TEMP・FLT DECK TEMP で 65〜85°F）と温度、パックの出口は最も冷たい空気が要るゾーンに合わせ（35°F、25,000 ft 超は 28°F 〜 135°F）、ほかのゾーンにトリム空気を足す。master trim air valve は TRIM AIR ON でパックが 1 基以上運転のとき開き、中央ダクトが無ければトリム空気は無い。backup（TRIM AIR off、ダクト過熱、ZTC の故障、中央ダクトなし）はゾーン弁 10 %、パックの出口で客室の平均を PASS TEMP の値（ZTC の故障では最後の値）に、F/D は 85°F まで。ダクト 185°F が 10 秒で master trim air valve をラッチで閉じ、ZONE RST で戻す（過熱が消えていれば）。comfort correction（cruise clamp と 25,000 ft 超で 2°F/h、2 時間で +4°F、85°F まで、descent detect で 5 分で戻し、その便ではもう使わない）。パックの cruise clamp の normal flow は客室が target の 1 ℃ 以内になるまで待つ（最長 20 分）。メッセージ：>TRIM AIR OFF（全パック OFF では出さない）、TEMP ZONE、ZONE SYS FAULT 灯（TRIM AIR off、過熱、ZTC、パックの空気があるのに弁が閉）、STATUS ZONE TEMP（70 秒）。
- ECS synoptic：7 ゾーンの target（左、小さく。パック運転中で backup でないとき）と actual、MASTER、FWD・AFT、外流弁の針と弁ごとの MAN（琥珀）・AUTO、パックごとの HI FLOW、EXT AIR を足した。パックの OFF は弁が閉、A・B は使用中の controller（前は選択器の位置）。エンジンと APU からの流れの線はその弁が開のとき（前はエンジンの抽気圧で、ENGINE BLEED OFF でも出ていた）。
- 貨物室：前方は機器冷却の排気（inboard exhaust valve が開のとき）と、40°F で入り 50°F で切れるヒーター（排気の弁が開でエンジン 2 基が 50 % 超）。後方は AFT CARGO HT で、エンジン運転中に選択温度でサーモスタットのように暖め、90°F 超で弁を閉じて TEMP 灯（地上では点かない）と TEMP CARGO HEAT、AFT の貨物室火災 ARM で止まる。

残っている違い：
- 3D の PASS TEMP・FLT DECK TEMP のノブは C〜W の範囲しか回らず、客室乗務員の温度パネル（door 2R）は 3D に無いので、PASS TEMP の ALTN（ゾーン A の専用 controller、125°F の過熱スイッチ）、FLT DECK の MAN、ゾーンごとの ±10°F は作っていない。温度の表示は ℃（ATA21 の会社の表示。FCOM 109 の図は °F）。EXT AIR は地上空気をつなぐ操作が無いので出ない（PNEU-07）。
- 推定：ゾーンと貨物室の熱のつり合い（熱の負荷 70 kW、スキン、熱容量、ゾーンごとの配分、トリム空気の強さ、ZTC の効き、パックの出口の遅れ）、エンジン停止で始めたときは外気温・エンジン運転中か空中で始めたときは target から始めること、後方貨物室の選択温度（40°F。選択スイッチは bulk 貨物室の中）とサーモスタットの幅、PASS TEMP を回すと comfort correction をその便では止めること、中央ダクトが無いときのメッセージ（出さない）、ZTC・トリム空気の弁の電源。backup で APU に最大流量を求めること（ATA21 p.368）は作っていない。
- 機器冷却と温度制御の故障（機器冷却の過熱・低流量・煙・ファン、ZTC、トリム空気の弁、ダクト過熱）を入れる手段が無い（モデルには入力がある）。clean mode と後方の lav/galley fan は無い。
- 純正 acf の data block は、客室高度の赤い数字が 4 桁（10,000 ft 以上で先頭の桁が欠ける）で、LDG ALT も両 CPC 故障・両方 MAN で消えない（直したのはカスタム acf のパネルだけ：AIR-18）。
- FMC の T/C・T/D・上昇時間を使わない（FMC にその出力が無い）。上昇は機体の上昇に比例、降下は降下に比例させた。進入を選んだときの滑走路の標高も使わない（FMC に到着ページが無い）。
- 推定：巡航の客室高度（ΔP 8.8。FCOM の表示例から）、客室の容積・パックの流量・弁の面積・漏れ・リリーフ弁の開き方、弁の速さ（自動 6 秒、手動 20 秒）、FMC なしで空中で始めたときの客室。
- パックの過熱は、温度のモデルの出口が 135°F 以下なので原因が無く、故障の入力のまま。再循環ファンの故障の入れ方が無い（X-Plane に相当する故障が無い）。CPC の故障は `laminar/B747/air/fail/cpc[0-1]` で入れる。
- 外流弁の自動のモーター、パック弁の継電器、再循環ファンの電源のバスは資料に無い（どれかの AC で動くとした）。

### 防氷・防雨（ATA 30）：作り直し済み（3-2）

実機に合わせた点：
- NAI：弁はエンジンの PRV の下流の抽気で開く（ENGINE BLEED が OFF でも NAI で PRV が開く。始動弁が閉じて 15 秒、火災スイッチ、PRV の過熱ラッチは抽気のモデル）。28V DC のソレノイド、カウルの過熱で閉じてスイッチを切るまでラッチ。VALVE 灯は弁がスイッチの位置と違う間、NAI VALVE n はエンジン運転中に 3.5 秒。主 EICAS の NAI は弁が開いたとき。
- WAI：空中でスイッチ ON のとき、AC bus 2 のモーターで左右の弁が 3 秒未満で開く（ダクト圧は見ない。前は 12 psi が要った）。地上では開かない。VALVE 灯は弁が指令と違う間、WAI VALVE LEFT・RIGHT は 5 秒。X-Plane へは左右別々に渡す（前は左右共通のコマンドで、片側が違うと毎フレーム入れ替わった）。
- 窓：風防 L・R を別々に加熱。スイッチ OFF・電源なし・制御器の故障で INOP 灯と HEAT WINDOW、故障は 10 秒切ってから入れ直すまで残る。側窓は AC で加熱。エンジン運転中の開始で WINDOW HEAT ON。
- プローブ：ピトー静圧（CAPT、F/O、L AUX、R AUX）と AOA はエンジン運転中、TAT は空中で加熱し、X-Plane の AOA・TAT の加熱も入れる（前はどれかのエンジンの抽気圧で「運転中」とし、AOA・TAT は無かった）。HEAT …（TAT は 15 秒）。
- 氷検知：空中だけ、左は AC bus 1、右は bus 3。>ICING、>NO ICING、>ICE DETECTORS（2 秒）、STATUS ICE DETECTOR L・R（12 秒）。>ANTI-ICE（防氷 ON で TAT 12°C 超、氷なし。前は出なかった）。
- ワイパー：28V DC、LO・HI を X-Plane の 50・100 %（前は 25・50 %）。エンジン始動の点火（NAI で連続点火）はスイッチの位置で決める。

残っている違い：
- 防氷による推力の補正（ICE-11。EEC の補正表の作り直しで）。逆推力中の NAI 弁の閉、NAI ダクトのリークと圧力スイッチのメッセージ、窓の STATUS（WINDOW HEAT 1L/1R/2L/2R）は無い。
- ワイパーは acf の最大（毎秒 2 回）なので、実機の LO 160・HI 250 回/分より遅い。ウォッシャーは効果が無く、防雨剤と WSHLD AIR は操作子が無い（ICE-10）。
- 氷の付き方と検知は X-Plane の着氷と ice の表示灯をそのまま使う（検知器の回数と保持時間の内部は作っていない）。>NO ICING を消す時期は資料に無く、着陸までとした（推定）。
- 推定：NAI 弁の開く抽気 12 psi と全行程 1 秒、WAI 弁の全行程 2.5 秒、地上で WAI ON のとき VALVE 灯を点けないこと、プローブ・窓・ワイパーの電源のバス、X-Plane に無い AUX のプローブを予備のピトー・静圧孔に当てたこと。プローブの地上の減電力は作っていない。

### 酸素（ATA 35）：作り直し済み（3-3）

実機に合わせた点：
- 乗客酸素：客室高度約 14,000 ft で自動で作動し、PASS OXYGEN を ON にすればどの高度でも作動する。RESET は客室 12,000 ft 未満でだけ効く。作動中は PASS OXYGEN ON、60 秒で STATUS PASS OXYGEN ON。NO SMOKING と FASTEN SEAT BELTS は選択器にかかわらず点く（前はサインの判定に TODO があるだけで、酸素の系統が無かった）。
- 治療用酸素：THERAPEUTIC OXYGEN の ON と、乗客酸素の自動作動で作動し、THERAP OXYGEN ON。RESET は 12,000 ft 未満。
- 酸素圧：STATUS ページに乗員と乗客（3 本の平均）の圧を出す（カスタム acf。前は表示の欄が空だった）。ボンベの温度（前方貨物室）で変わる。500 psi 以下で >CREW OXY LOW。
- 乗員マスク：出すと酸素が流れ、しまって RESET/TEST を押すまで流れる。X-Plane の酸素系統を上書きし、マスクを出していれば X-Plane の低酸素の効果を抑える（前は X-Plane の乗員酸素のボンベが 0 L で、減圧すると防ぐ手段が無かった）。

残っている違い：
- 3D に酸素のスイッチとマスクの操作子が無いので、コマンド（`laminar/B747/oxygen/…`）をキーに割り当てて使う。準備の手順の乗員マスクの試験（RESET/TEST で圧を見る）は無い。客室の蛍光灯とチャイム（減圧リレー）は無い。
- 推定：出発時の圧（満充填）、使う量（乗員マスク 2 人で約 6 時間、乗客酸素は約 30 分）、マスクを着けたときの低酸素の高度（10,000 ft まで）、ソレノイドの電源（どれかの DC バス）。
- 純正 acf の STATUS ページには酸素圧が出ない（パネルを変えていない）。

### 火災防護（ATA 26）：作り直し済み（3-4）

実機に合わせた点：
- 検知：エンジンの火災と過熱、APU の火災に双ループの検知器（APU battery bus）。エンジンは 2 ループとも感じたときに警報し、片方のループが故障すればもう一方だけで警報する。APU はどちらかのループで警報。両ループの故障で >DET FIRE/OHT n・>DET FIRE APU。STATUS の loop のメッセージと FIRE/OVHT SYS（前は X-Plane の火災表示の素通しで、APU は故障の予約だけで灯が点いた）。
- メッセージ：FIRE ENG n、FIRE APU、OVHT ENG n NAC（新設）、>BTL LO L/R ENG A/B（前は FCOM に無い名前）、>BOTTLE LOW APU。FIRE のメッセージでベルと master WARNING が出る（1-3 の警報のモデル）。
- 消火スイッチ：火災警報・FUEL CONTROL の CUTOFF・試験で解錠され、それ以外は引けない（main hot battery bus）。Fire Override はコマンド。回した向きのボトルを 1 回だけ放出し、翼の 2 エンジンでボトルを共用する（空のボトルでは消えない。前は回している間ずっと X-Plane の消火器が入った）。BTL DISCH の灯。
- 消火スイッチを引くと、燃料弁・spar valve・抽気弁・油圧に加えて発電機の GCR がトリップし、スイッチを戻しても GEN CONT を OFF→ON にするまで戻らない（ラッチ式のリレー）。
- APU：火災で APU を止め（試験では止めない）、地上では APU が 95 % 未満のまま 10 秒で APU ボトルを自動で放出する。APU の消火スイッチ（引く・回す・override）はコマンド。APU BTL DISCH の灯。
- FIRE/OVHT TEST：押している間、消火スイッチ・APU・貨物の灯、>TEST IN PROG、5 秒で >FIRE TEST PASS（ループが 1 本でも故障か電源が無ければ FAIL。貨物・車輪格納部・ダクトの検知器も含む）。離すと消える。
- 下部貨物室：煙検知器（ゾーンごとに 2 ループ、電源投入と試験のときに組み替え）、FIRE CARGO FWD・AFT と灯、ARM・DISCH で A・B を即時に、C・D を 30 分後か接地で（前は ARM・DISCH を誰も読まず、灯も常に消えていた）。DISCH の灯、>CGO BTL DISCH、>CARGO DET AIR。
- 車輪格納部の火災（FIRE WHEEL WELL）、主翼前縁の過熱（BLD DUCT LEAK L・C・R）、化粧室とクルーレストの煙（>SMOKE LAVATORY、SMOKE DR 5 REST）。スクイブ試験（TEST 1・2 のコマンドと緑の灯）。

残っている違い：
- 貨物室の煙、車輪格納部の火災、ダクトリーク、化粧室・クルーレストの煙、ナセルの過熱は X-Plane に無いので、失敗の dataref（`laminar/B747/fire/fail/…`）で起こす。ダクトリークでダクト圧は下がらない（抽気の残り）。クルーレストの煙で給気弁とファンは止まらない。
- FUEL CONTROL の赤灯は 3D が X-Plane の火災表示に付いているので、X-Plane のエンジン火災では点くが、試験やループの故障の結果には合わない。APU の消火スイッチと Fire Override は 3D に操作子が無い（コマンドで操作）。M869（脚格納部の APU 火災パネル）と APU 火災のホーンの音は無い。
- 過熱の原因（X-Plane に無い）は失敗の dataref で起こす。
- 推定：ボトルが空になるまで 1.5 秒、X-Plane のエンジン火災は過熱の検知器に伝えないこと、APU ボトルで X-Plane の APU 火災を消すこと、貨物の剤で煙の失敗を消すこと、venturi の吸引の閾値（中央ダクト 5 psi）、貨物の検知の電源。
- 貨物機の主デッキの火災（FIRE-19）。

### 操縦系統（ATA 27）：作り直し中（4-1。フラップ・SRM は済）

直した点：ラダートリムが舵面に入る（全行程の 80 %、比率変換器を通る。前は舵面が動かなかった）。舵面位置のスポイラーはスポイラー 4・12（前は平均）。フラップレバーのスナップ。

- 安定板トリム（段 2b、SRM のモデル）：速さは 1 unit = 1°（ATA22 p.132）で、両方の STCM で 220 kt 以下 0.5 units/s・230 kt 以上 0.2、片方で半分（前は X-Plane のコマンドで対気速度に依らず約 0.3 units/s）。電気トリムの範囲 1.8（脚 down か前縁が出ていると 0.8）〜11.6、ALTN 0.25〜14.75（前は 0〜15 のどこまでも）。操縦桿をトリムと逆に引くと止まる（column cutout）。機長と F/O のスイッチが逆なら動かない。A/P 1 台で操縦輪のスイッチを使うと A/P が外れ（AUTOPILOT DISC）、2 台以上では効かない。ALTN は A/P を外さず、A/P 中に使うと STAB TRIM UNSCHD。油圧 2・3 の片方を失うか cutout スイッチを CUTOUT にすると半分の速さで >STAB TRIM 2・3、暴走は自動遮断で止まる（>STAB TRIM。cutout が ON なら STAB TRIM UNSCHD）。オートトリムは SRM がその SRM の STCM で半分の速さ、3.5 秒の遅れの後に動かす（前は狙いの約 1/60 の速さ）。A/P が外れると A/P の昇降舵・補助翼の指令は 0 に戻る（前は残り、操縦桿の位置がずれた）。STATUS の STAB TRIM・STAB TRIM UNSCHD・STAB AUTO TRIM。ALTN と cutout スイッチは 3D に操作子が無いので、コマンドで操作する。
- speed trim とグリーンバンド（段 2c）：A/P が外れていて 220 kt 以下なら、離陸 20 秒後から安定板が速度に応じて動く（120〜220 kt で 2.55 units 機首上げ、係合時の速度と位置から。ATA22 p.159）。前は無かった。STATUS STAB SPEED TRIM。グリーンバンドは 3 帯（mid 3.35–8.15、nose up 3.35–10.15、nose down 1.35–8.15）から選ばれ、地上で V1 未満なら指示器に出て、V1 を超えると mid に戻る。CONFIG STAB は選ばれた帯で判定する（前は FMC トリム ±2.25 units の帯で、帯の上端・下端が実機と違った）。

- 外側エルロンのロックアウトとラダー比変換器（段 2a、SRM のモデル）：ロックアウトは、前縁 group A が入っていて 238 kt か M .53 を超えるとロック、group A が出るか 232 kt と M .51 を下回ると外れ、間は保つ（前は 232→238 kt の直線で、フラップも Mach も見なかった）。SRM の故障で他方が引き継ぎ、両方失うと空中ではロックを外す。アクチュエータが動かないと 90 秒で AILERON LOCKOUT。ラダー比変換器は上下別々に速度の表（155.5 kt まで全権限、450 kt で 5°）で動き、エアデータを失うと上は 329 kt・下は 209 kt の位置、autoland では全権限、故障した変換器はその位置のまま（RUD RATIO SNGL・DUAL）。ペダルとラダートリムを足してから比変換器を通すので、高速で舵角が比の上限を超えない（前は和が制限されず、450 kt でも 9° 近く出た。空中ではトリムが二重に効いてもいた）。
- フラップ（段 1、FCU のモデル）：後縁は内側（系統 1）・外側（系統 4）の群ごとに油圧の主系統と電動の副系統。指令して 1400 psi 未満が 4 秒、または動かないまま 7 秒（脚の動作中は 42 秒）で副系統（FLAPS PRIMARY）。圧が戻れば主系統に、圧があるのに副系統になった群は格納して 10 秒で戻る。2000 psi の priority valve。副系統で 25 秒動かないか、左右の差が 6.2 %（内側）・3.4 %（外側）を超えると、その群は止まる（FLAPS DRIVE）。前縁は内側・中央・外側の群ごとに空気圧（各翼のダクト圧）と電動。動かないと 30 秒で両翼とも電動（内側と中央は一緒）、指令の位置に着くと空気圧に戻る。電動は空気圧の 10 倍の時間（約 90 秒）。代替フラップ（ARM で FLAPS CONTROL、レバーは効かず、EXT で全群が電動ですぐ動き後縁は 25 で止まる、RET で前縁は内側の後縁が UP になってから）。順序（1 で group A、5 で group B と後縁、格納は内側の後縁が 4.5° 未満で group B、外側の後縁が UP で group A）。地上の逆推力（1・4 か 2・3）で group A を格納。荷重軽減は後縁が両方とも主系統のときだけ。EICAS の表示は、UP と 1 の間は group A の動き、1 から上は最も遅い後縁の群。マゼンタはレバーの位置に全部が着くまで。副系統・停止・非対称・代替で拡大の表示。STATUS の TE FLAPS・LE SINGLE DRIVE・LE MULT DRIVE・FLAP CONTROL・FLAP LOAD RELIEF。外側フラップの wing 2 の部分（acf のフラップの組 2）も動く（前は空力上 0°）。

残っている違い：

- フラップ：拡大・代替の表示のパネル（前縁の 6 箱、琥珀、amber X、代替の目盛り：FCTL-12）が無く、拡大は後縁 4 本だけ。後縁の主系統の速さ（30° を 45 秒）と副系統の速さ（その 1/10）、前縁の電動の故障で止まるまでの時間、前縁の制御の電源は資料に無く推定。逸走と moving away の保護は作っていない（故障の源が無い）。故障は `laminar/B747/flt_ctrls/fail/...` で入れる。
- 安定板トリム：電波高度 500 ft 未満ではオートトリムしない（前のまま。実機は接地まで、LAND 2 の 120 ft 未満は全速と機首上げの bias：AFDS の作り直しで）。MOV の故障（STAB AUTO CUTOUT）、スイッチの片方だけの操作は作っていない。推定：STCM が動く圧 1000 psi、監視が見つける動き 0.1 units、dead trim の 2 秒、column cutout を操縦桿の行程の 35 %、A/P が外れたときの指令の戻り（毎秒 1）。プラグインが X-Plane に渡す安定板の角度は 1 unit 2°（実機は 1°）のまま（空力がこれで調整されている）。
- ヨーダンパーの舵角にもラダー比をかけている（実機は比変換器の下流で足す：推定）。ラダー比変換器の速度の表の点の間とアクチュエータの速さは推定。
- 自動スピードブレーキの着陸展開は X-Plane 任せ（FCTL-07）。SPEEDBRAKES EXT の条件（FCTL-08）。
- 横操縦の舵角の対応、フラップ表示の拡大・代替形式（FCTL-09・12）。グリーンバンドの選び方は FMC の離陸トリムからの推定（MAWEA の表は資料に無い）で、3D の帯は 1 本の長さ 4.63 units なので nose up・nose down の帯は外側の端だけを合わせて出す。>STAB GREENBAND は前脚の圧力スイッチの設定値が資料に無く、作っていない（FCTL-10 の残り）。
- ヨーダンパーの INOP の条件（FCTL-15）。電源への依存が無い（FCTL-25）。

## 3. X-Plane の上で作ることによる違い

- 推力・燃料流量・空力は X-Plane の計算。燃費は acf の SFC で決まる（燃料 2-2 で値を確かめる）。
- 脚・ブレーキ・オートブレーキは、作り直すまで X-Plane の仕組みのまま。逆推力は、動ける条件は作り直したが、展開・格納の動きと推力は X-Plane の計算。
- 与圧は X-Plane の与圧に値を書いている（空調 3-1 まで）。
- 経路と ND の経路線は X-Plane 標準の FMS（FMC の作り直しまで）。
- X-Plane 側の制約（試験で見つけたもの）：機体を読み直さずにフライトを始めると前のフライトの状態が残る系統がある。XP12 の外部電源は X-Plane の GPU 電圧に従う。X-Plane の抽気のモードと isolation valve は連動する。Web API の長さ 0 のコマンドは離す操作が届かない。
