# カスタム acf の空力の比較（PROGRESS.md 次にやること 5f）

カスタム acf（`747-400_custom.acf`）の飛び方を、FCOM・FCTM の目安と比べ、ずれていれば acf の空力を調整する（2026-10-28 の利用者の指示。見た目が変わらない範囲で承認なしでよい：CLAUDE.md。手順はバックアップ・ACF_DIFF.md §5 の前後の値・外観の写真）。飛行特性のずれをシステム側の補正でごまかさない。

## 1. 目安

### 1.1 縦（FCOM PI.10.38–10.40、p.264–266、PW4056）

Flight With Unreliable Airspeed の表。重量 200〜390 t（終端区域と最終進入は 410 t まで）ごとに、姿勢と推力（EPR・N1）、上昇と降下は昇降率。値は `tests/flight/tools/aero_compare.lua` に写した（重量と高度で内挿する）。

- Climb（290/.84、フラップ UP、最大上昇推力）：海面〜40,000 ft の姿勢と昇降率。
- Cruise（.84/290、水平）：姿勢・EPR・N1。
- Descent（.84/290、アイドル）：姿勢と昇降率。
- Holding（10,000 ft、フラップ UP、水平）：姿勢・EPR・N1・KIAS。
- Terminal Area（5,000 ft、水平）：フラップ UP（VREF30+80）・1（+60）・5（+40）・10（+20）・20 と脚下げ（+10）。
- Final Approach（1,500 ft、脚下げ、3° のグライドスロープの EPR）：フラップ 25（VREF25+10）・30（VREF30+10。300 t まで）。
- 速さ 290/.84 の切り替わりは約 34,500 ft（.84 は 35,000 ft で 287 KIAS、30,000 ft で 321 KIAS：標準大気で計算）。

例（約 270 t、250 t と 300 t の間を内挿）：巡航 35,000 ft は姿勢 2.2°・EPR 1.18・N1 84.3 %、待機は 6.0°・EPR 1.02・231 kt、終端区域は UP 5.5°・1 7.0°・5 7.7°・10 8.5°・20 7.5°、最終進入はフラップ 25 で 2.0°・EPR 1.06、30 で 1.0°・EPR 1.10、アイドルの降下は 20,000 ft で −0.6°・−2,160 fpm、10,000 ft で −0.4°・−1,860 fpm、上昇は 10,000 ft で 9.3°・3,740 fpm、20,000 ft で 6.8°・2,820 fpm、30,000 ft で 4.5°・1,600 fpm。

### 1.2 縦（FCTM）

notes/FCTM.md §1.13 の早見表から：

- 3°・フラップ 30・VREF30+5 で姿勢 2.0°（FCTM p.168）。FCOM の最終進入（VREF30+10 で 1.0°）と 1° 違う：FCOM を優先する（CLAUDE.md）。
- 引き起こしは平均約 2.5°/s で 15° へ、浮揚は 3〜5 秒、浮揚の姿勢 10.0°（フラップ 20）・10.1°（10）（FCTM p.95–96）。
- アイドルの降下率：.83M/340 kt で 2,800 fpm（スピードブレーキで 4,300）、250 kt で 1,300（2,100）、VREF30+100 で 1,200（1,900）（FCTM p.138。重量の記載なし）。
- 水平の減速 340→250 kt は 90 秒・8 NM（FCTM p.139）。
- 速度計異常の姿勢：巡航 3°、降下 0°、最終進入（VREF+10）でフラップ 25 は 2.5°・30 は 1°（FCTM p.294）。
- 失速速度とシェーカー：notes/FCTM.md §1.14（2026-10-25 に合わせた：ACF_DIFF.md §5）。

### 1.3 横・方向

- VMCG（FCOM p.236 (PI.10.10)、最大離陸推力）：海面・15 °C で 121 KIAS。外側のエンジンを VMCG で止めてラダーだけで方向を保てること。逸脱の量の基準は資料に無いので記録だけ（推定）。
- 片発と 2 発停止：ラダートリムで操縦輪が水平になること（FCTM p.55 (1.25)）。同じ側の 2 発停止の着陸復行ではラダートリムいっぱいでもペダルが少し要ること（FCTM p.209）。
- 横風：最大離着陸横風 30 kt（実証値：FCOM p.77 (L.10.1)）、FCTM p.99・p.241 の目安。舵がいっぱいにならずに離着陸できること。
- ダッチロールとロールの速さは資料に値が無い。ヨーダンパーの入・切で見て、明らかにおかしいときだけ報告する。

## 2. 測り方

- 測定のシナリオ（`tests/flight/measure/`、合否なし、全シナリオの実行に入れない）。銚子沖の海上で空中から始め、A/P と A/T で保ち、落ち着いたら mark。上昇と降下は FLCH で通り抜ける。
  - `aero_cruise_descent.json`：35,000 ft の .84（287 KIAS）の水平、A/T を切ってアイドルで 290 kt の 8,000 ft への降下。
  - `aero_climb_maxclb.json`：8,000 ft から FLCH 290 kt で、A/T を切って FlyWithLua の `tests/flight/fwl/B747_epr_hold.lua` でレバーを FCOM PI.10.36 の Max Climb EPR（気圧高度と TAT）に合わせ、34,000 ft まで（利用者の希望：A/T の CLB の基準は ATHR-04 で最大上昇推力ではない）。
  - `aero_flaps.json`：5,000 ft でフラップ UP・1・5・10・20（脚下げ）・25・30 を FCOM の速さで水平に（25・30 は最終進入の速さ）。
  - `aero_holding_terminal.json`：10,000 ft の待機（231 kt）と 290 kt、5,000 ft の終端区域のフラップ UP・1・5・10・20（脚下げ）。速度は機体の VREF30 とフラップの機動速度（`laminar/B747/airspeed/Vf0`〜`Vf20`）。
  - `aero_final.json`：3,000 ft からフラップ 25（VREF25+10）と 30（VREF30+10）、脚下げで V/S の 3° の降下。
- 読み方：`luajit tests/flight/tools/aero_compare.lua <記録のフォルダー> [窓の秒] [時刻...]`。mark の後の窓（既定 30 秒）を、フラップ・高度・速度から表の行に当てて平均し、FCOM の値との差を出す。上昇と降下は、フラップ UP で表の高度を通る所の上下 300 ft の平均。標準大気で Mach と経路角も出す。
- EPR と N1 は X-Plane のエンジンの値（`sim/flightmodel/engine/ENGN_EPR`・`ENGN_N1_`）。エンジンの表示値の作り方（ENG-33）は未着手で、X-Plane のエンジンの EPR と推力の関係は実機と同じとは限らない。推力の比べ合わせは、アイドルの降下率（抗力）と分けて読む。
- 上昇の推力は実機の最大上昇推力ではない：A/T の THR REF の CLB の基準は、前のコードの「決まった上昇率（PW4056 で 10,000 ft 未満 2,750 fpm など）に要る EPR」（ATHR-04、6-4 で直す。FCOM PI.10.36 (p.262) の Max Climb EPR は 10,000 ft で約 1.35、20,000 ft で 1.43）。2026-10-29 の測定でも 9,000 ft で EPR の基準 1.19・実際 1.28、昇降率 1,800 fpm（FCOM は 270 t・10,000 ft で 3,740 fpm）。そこで上昇は昇降率でなく、姿勢から経路角を引いたもの（無風での迎角：推力が違っても変わらない）で比べる。降下と最終進入も同じものを出す。
- アイドルの降下では、経路角の正弦が（抗力 − アイドル推力）÷ 重量。FCOM の降下率から同じものを出し、比を見る（アイドル推力が小さいので、ほぼ抗力の比）。

## 3. 結果

### 3.1 変更前（2026-10-29、カスタム acf、約 269 t、重心 31.5 % MAC、P&W）

姿勢の差は「姿勢 − 経路角」（無風の迎角）の X-Plane − FCOM。FCOM の姿勢は 0.5° 刻み。

| 状態 | X-Plane | FCOM | 差 |
|---|---|---|---|
| 待機 10,000 ft・231 kt | 4.60° | 6.0° | −1.4 |
| 10,000 ft・290 kt 水平 | 2.06 | 2.89 | −0.8 |
| 35,600 ft・M.848 水平 | 1.71 | 約 2.2 | −0.5 |
| 5,000 ft・231 kt UP | 4.83 | 5.5 | −0.7 |
| フラップ 1（VREF30+60） | 6.11 | 7.0 | −0.9 |
| 5（+40） | 6.18 | 7.7 | −1.5 |
| 10（+20） | 6.77 | 8.5 | −1.7 |
| 20・脚下げ（+10） | 3.95 | 7.5 | −3.6 |
| 25（VREF25+10、水平で迎角を比べた） | 2.63 | 5.0 | −2.4 |
| 30（VREF30+10、3° の降下：姿勢 0.75°、FCOM 1.0°） | 3.76 | 4.0 | −0.2 |
| 上昇 20,000・30,000 ft（最大上昇 EPR） | 1.62・1.39 | 2.66・2.34 | −1.0・−0.9 |
| アイドルの降下 10,000・20,000・30,000 ft（290 kt） | 1.91・1.27・1.29 | 2.74・2.55・2.53 | −0.8・−1.3・−1.2 |

- 揚力：クリーンで平均約 1.0° 機首が低い（同じ揚力をより小さい迎角で出す）。フラップの揚力の増し分（同じ迎角で比べたもの）は、X-Plane が 5：0.14、10：0.30、20：0.67、25：0.68、30：0.67 と 20° で頭打ち、FCOM から出すと 0.16・0.31・0.51・0.60・0.74 と増え続ける（揚力の傾きは両方ともほぼ 0.07〜0.08/°、主翼面積は比にだけ効く）。20 と 25 は揚力が大きすぎ、30 は足りない（10-25 の失速の調整で、20 だけ失速速度が 5 kt 低かったのと合う）。
- 降下：アイドルの降下の経路角は FCOM の 1.5〜1.6 倍急（290 kt で 10,000 ft −2,939 fpm／FCOM −1,861、20,000 ft −3,287／−2,161、30,000 ft −3,618／−2,261）。X-Plane のエンジンはアイドルで 1 発あたり −14〜−16 kN（負の推力）。
- 上昇（FlyWithLua で EPR を FCOM の Max Climb EPR に合わせた）：EPR は目標の ±0.003 に入る。昇降率は 20,000 ft で 1,874 fpm（FCOM 2,839、−34 %）、30,000 ft で 1,382（1,727、−20 %）。1 発の推力は 20,000 ft で 89 kN、30,000 ft で 76 kN。
- 巡航（35,600 ft・M.848）：EPR 1.51（FCOM 1.18）、N1 87.6 %（84.3）、1 発 54 kN、揚抗比（重量 ÷ 推力の合計）約 12。
- 水平飛行の N1 は FCOM より −1〜−7 %（フラップを出すと差が大きい）なのに、EPR は +0.05〜+0.5 高い：X-Plane のエンジンの EPR と N1 の関係が実機と違う（ENG-33 の表示値、A/T・EEC の EPR の目標に効く）。
- 上昇（推力 − 抵抗）と降下（抵抗 − アイドル推力）から出した抵抗が食い違う（20,000 ft・290 kt で 230 kN と 168 kN）ので、記録に X-Plane の空力とエンジンの力（`sim/flightmodel/forces/faxil_aero`・`fnrml_aero`・`faxil_prop`・`fnrml_prop`）を足した（記録スクリプト v4）。道具は風軸の揚力・抗力・経路方向のエンジンの力を出す。
- 測り方の落とし穴：上昇中に Mach が .84 を超えると、前の A/P のコードが MCP を Mach 表示に替え、IAS の数字を書くと Mach と読む（287 → M2.87 で目標が最大速度になった）。測定は 35,000 ft から IAS 表示のまま始める（`aero_cruise_descent.json`）。

### 3.2 変更 1：主翼の取り付け角 −1.0°（2026-10-29）

主翼（wing 0〜7）の取り付け角を、ねじりを保って 1.0° 下げた（ACF_DIFF.md §5、`docs/overhaul/tools/acf_aero.lua`）。

| 状態 | 迎角の差（前 → 後） |
|---|---|
| 5,000 ft・231 kt UP | −0.7 → +0.1 |
| フラップ 1・5・10 | −0.9・−1.5・−1.7 → −0.2・−0.7・−0.4 |
| 20（脚下げ）・25・30 | −3.6・−2.4・−0.2 → −2.0・−0.9・+0.2 |
| 35,500 ft・M.847 の姿勢 | 1.71 → 2.67（FCOM 約 2.2） |
| 上昇 20,000・30,000 ft | −1.0・−0.9 → −0.1・0.0 |
| アイドルの降下 10,000・20,000・30,000 ft | −0.8・−1.3・−1.2 → +0.1・−0.3・−0.3 |

クリーンはほぼ合った（±0.3°、巡航は +0.4°）。

力で分けて読んだ抵抗とエンジン（記録 v4、取り付け角の変更後）：

- 空力の抵抗 ÷ 重量は、290 kt で 0.0805（10,000 ft）・0.0788（20,000）・0.0770（30,000）、巡航 M.847 で 0.0796。揚抗比は 12.4〜12.9。上昇でも降下でも同じ値で、前の食い違い（§3.1）はエンジンの力の向きと加速の分だった。
- アイドルのエンジンの力（経路の向き）÷ 重量は −0.018〜−0.024（1 発 −12〜−16 kN）。
- FCOM のアイドルの降下が決めるのは（抵抗 − アイドル推力）÷ 重量 ＝ 0.049〜0.055（290 kt）。X-Plane は 0.079〜0.087。資料は合計しか決めないので、抵抗とアイドル推力の分け方は推定になる。実機のアイドル推力を 0 に近いとすると、抵抗は約 30 % 多すぎ（揚抗比で約 18 が目安）、アイドル推力も負に大きすぎる。
- 最大上昇 EPR の推力（経路の向き）÷ 重量：20,000 ft で 0.136（1 発 90 kN）、30,000 ft で 0.117（76 kN）。FCOM の昇降率に要る（推力 − 抵抗）は 0.072・0.037 なので、いまの抵抗のままなら 30,000 ft では足り、20,000 ft では足りない：X-Plane のエンジンの推力の高度による落ち方も実機と違う。抵抗とエンジン（アイドル推力・EPR と推力・高度の落ち方）は一緒に合わせる。

### 3.3 変更 2：フラップの最後の detent 40 → 50°（2026-10-29）

X-Plane のフラップの揚力の増し分（同じ迎角で比べたもの）は、最後の detent（40°）の半分の 20° まで比例して増え、その先は増えなかった（20・22（25 の位置）・30° で同じ）。FCOM の姿勢から出す増し分は 30° まで増え続ける。最後の detent を 50° にして比例の範囲を 25° まで広げた（`_flap1_cl` はそのまま。予想の迎角の差：5 −0.2、10 +0.6、20 −0.1、25 +0.3、30 +0.4°）。FCU が角度を自分で書き、3D のフラップは別の dataref で動くので見た目は変わらない。

結果は予想より小さかった（迎角の差、detent 40 → 50）：5 は −0.71 → −0.53、10 は −0.39 → −0.22、20 は −2.03 → −1.61、25 は −0.90 → −0.73、30 は +0.24 → +0.68。最大の detent で比例の範囲が決まる形ではなかった。20・25・30° の増し分がそろうのは、翼型の揚力曲線の丸み（2026-10-25 の失速の調整で、主翼の翼型の失速を 2.8° 早めた）に、フラップの分の迎角が入るためと見られる（推定）。差の合計は少し減り（4.5 → 4.0°）、着陸の 30 は FCTM の 3°・VREF30+5 の 2.0°（FCOM の VREF30+10 は 1.0°）の間に入るので残した。20 の揚力が大きすぎる（−1.6°）のは残る。

失速速度（`stall_*.json`、1 g、約 270 t、10,000 ft。FCTM との差、括弧は 2026-10-25 の調整の後）：UP 169.3 kt（−3.4、−2）、10 は 139.8（+2.2、+6）、20 は 127.7（−5.5、−5）、30 は 126.0（+4.1、+4）。30 では失速のとき昇降舵がほぼいっぱい（0.98）：取り付け角を下げて失速の姿勢が 1° 上がった分。水平安定板と昇降舵の効き（引き起こし・フレア）は次に確かめる。

外観（`aero_exterior_ground.json`・`aero_exterior_air.json`、2026-10-29）：地上は 2026-10-24 の写真と同じ形。巡航（35,000 ft・.84）と旋回（A/P の bank limit で 15°）の翼の曲がりは自然（翼端のたわみ `wing_tip_deflection_deg` −4.8°・−4.75°）。

### 3.4 変更 3：ナセルとフェアリングの抵抗（2026-10-29）

`aero_drag.json`（10,000 ft で 290 kt と 231 kt の水平、揚力係数 0.36 と 0.56）で、物体の抵抗係数を 1 つずつ変えて CD の変わり方を測った（主翼 541.2 m² を基準）：

| 変えたもの | CD（CL 0.36／0.56） | 抵抗係数 1 あたりの CD |
|---|---|---|
| 変更前 | 0.0288／0.0392（CD0 0.0217、誘導抵抗の係数 0.056） | — |
| ナセル 4 つ（body 21〜24）0.1 → 0.04 | 0.0256／0.0359 | 0.054 |
| 胴体（body 0）0.085 → 0.055 | 0.0267／0.0370 | 0.071 |
| 翼胴フェアリング（body 1）0.06 → 0.03 | 0.0280／0.0381 | 0.032 |

- 胴体の分（0.085 × 0.071 ＝ 0.0060）は、表面の摩擦からの見積もり（濡れ面積約 1,800 m²、約 0.0066）と同じなので変えない（推定の見積もり）。
- ナセルの分（0.1 × 0.054 ＝ 0.0054）は、外側の表面の摩擦の見積もり（約 0.0013）の 4 倍。X-Plane のエンジンの推力（正味）に吸い込みの抵抗が入っているので、ナセルを詰まった物体として扱う分は重複と見る（推定）。ナセルを 0.025、フェアリングを 0.03 にした（ACF_DIFF.md §5。CD0 は約 0.0166 の見込み）。
- 残りの降下率の差は、アイドル推力（いま 1 発 −12〜−16 kN）と主翼の抵抗の分け方で、資料は合計（FCOM の降下）しか決めない。エンジンの調整で扱う。

結果（`aero_drag`・`aero_cruise_descent`・`aero_climb_maxclb`）：

- CD0 0.0217 → 0.0169（誘導抵抗の係数 0.055 は同じ）。揚抗比は 10,000 ft の 290 kt で 14.9、231 kt で 16.4、巡航（35,600 ft・M.85）で 14.3（前は 12.4）。巡航の推力は 1 発 53 → 46 kN。
- アイドルの降下（290 kt）：（抵抗 − 推力）÷ 重量は FCOM の 1.32〜1.40 倍（前は 1.52〜1.60）。昇降率は 10,000 ft で −2,533 fpm（FCOM −1,861）、20,000 ft で −2,854（−2,161）、30,000 ft で −3,165（−2,261）。抵抗だけなら 1.2 倍で、残りはアイドル推力（重量の −0.018〜−0.024）。
- 最大上昇 EPR の上昇：20,000 ft で 2,319 fpm（FCOM 2,836、−18 %。前は −34 %）、30,000 ft で 1,843（1,722、+7 %）。一定 IAS の上昇の加速の分（重量の 0.013〜0.016）を入れて（推力 − 抵抗）÷ 重量で比べると、30,000 ft は FCOM と合い、20,000 ft は約 0.018（1 発 12 kN）足りない：X-Plane のエンジンの推力の高度（Mach）による落ち方が実機と違う。
- 姿勢（迎角）は降下でも ±0.4° に入ったまま。
- 外観（2026-10-29 23:37〜23:41、地上・巡航・15° の旋回）は変わらない（翼端のたわみ −4.77°・−4.75° で前と同じ）。
