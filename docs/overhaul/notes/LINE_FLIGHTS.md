# 試験ラインフライト（通しの飛行）

離陸から着陸・停止までを一つの筋書きで飛び、系統どうしのつながりと、FCOM・FCTM の目安に合うかを見る。筋書きは `tests/flight/scenarios/`、記録は `tests/flight/runs/` と `Output/B747_flighttest/`。見つけたことは、直した段の notes と PROGRESS.md に移す。

## 1. s198：RJAA 34L → RJBB 06L（2026-11-01、1 回目）

- 筋書き（`s198_line_flight_rjaa_rjbb`）：RJAA 34L でエンジン運転中に始め、RTE（RJAA、RJBB、DIRECT XAC、DIRECT ATMUG）、ARR（STAR ATMUGA、ILS06LY、遷移 GATES）、PERF（ZFW 200、CRZ ALT FL250、COST INDEX 100）、TAKEOFF（フラップ 20、V 速度）。離陸、A/P CMD L、VNAV SPD・LNAV、フラップ上げ、11,000 ft の速度、FL250 の巡航、T/D の前に MCP 2,000 ft、降下、on approach の後の速度介入とフラップ、APP、LOC・G/S、LAND 3、フレア、接地、逆推力、ROLLOUT、停止。写真は PROGRESS の出発前、上昇と巡航の PFD・ND・PROGRESS、G/S の PFD。
- 結果：52/52（失敗・警告なし）。ただし途中で乗員の操作を 3 つ入れた（下の 4.）。Log.txt に Lua の誤りなし。
  - 離陸から巡航：VNAV SPD・LNAV、FL250 まで 642.9 s、巡航 35 分は FL250 の ±12 ft（7154 回の取得）。
  - 降下：T/D で相 3（VNAV PTH、A/T IDLE）、1 分後に -1,327 fpm。10,000 ft の下まで 556 s。
  - 進入と着陸：GATES の先で on approach、LOC 捕捉、G/S 捕捉、LAND 3、FLARE、接地は -454 fpm・151 kt・滑走路端から約 870 m、ROLLOUT で LOC のずれ 0.02〜0.04 ドット、スピードブレーキは接地で自動で UP、60 kt の後パーキング・ブレーキで停止。
- 見つけたこと（直す候補。記録 `Output/B747_flighttest/session.csv` の fvn_* の列で確かめた）：
  1. 10,000 ft を 291 kt で通過（VNAV の目標 240 kt）。FCOM p.1264 の 4 は「速度制限の高度の手前で目標速度にし、VNAV PTH のまま約 500 fpm で降りる」。今の経路（B747.68.pred_model.lua の descent_path）は制限の高度で水平に減速する（推定だった）。制限の高度を過ぎてから DRAG REQUIRED が出て、9,400 ft で水平にして減速した。
  2. T/D の水平の減速が無い。FCOM p.1264 の 2 は「T/D で降下の段に移り、ECON の降下速度へ高度を保って減速し、近づいてから降りる」。今は T/D で巡航の 333 kt のまま -2,700 fpm で降り始めた。
  3. T/D の直後、ATMUG での約 180° の旋回（バンク 25°、GS 420 kt）の間に、E/D までの距離（機体から今の点まで直線＋その先の残り：B747.68.xt.fms.lua の inp.d_ed）が 80.8 から 85.0 NM に増え、経路の下 2,000 ft として約 1 分水平に飛んだ。その後は経路の下約 360 ft を -1,650 fpm で降りた。旋回の弧を経路の距離に入れていないため（FMC は旋回に沿う）。経路そのもの（XAC から西の ATMUG へ行き、STAR で東へ折り返す）も、東から来る便には不自然。
  4. 進入で、VNAV の経路が G/S の約 0.6 ドット下を平行に降り、VNAV PTH のままでは G/S を捕捉しなかった。乗員の操作として V/S で G/S の下から近づけて捕捉した。
  5. 接地の -454 fpm はやや強い。停止後の EICAS に ENG 1〜4 REVERSER（逆推力の後で格納されていない）と >AUTOSTART OFF、FUEL PRESS CTR L・R。記録の始め（再読み込みの直後の約 2.6 秒）に EGT が 900〜2,566 になる値がある。いずれも原因はまだ調べていない。
  6. ND の S/C（ステップクライムの点）が巡航中に機体のすぐ前に出ていた（T/D まで 150 NM ほど）。
- 筋書きの誤り（次の回で直す）：
  - STAR ATMUGA は ATVID で終わり、ILS06LY の遷移 GATES とつながらず ROUTE DISCONTINUITY のまま降下した。RJBB の CIFP では ILS06LZ に ATVID の遷移がある（I06LZ）。今回は 17:02 に LEGS で DIRECT TO GATES（乗員の操作）を入れて続けた。
  - A/P を CMD L しか入れておらず、LAND 3 にならない。17:13 に CMD C と CMD R を入れた（FCOM の自動着陸の手順のとおり）。
  - 4. の V/S（17:11）。
- その後（2026-11-01、LF1：notes/ATA-34-61-FMC.md §123）：1. と 2. を直した（FCOM p.1264 の降下の減速と T/D の水平の減速）。4. は MCP の高度の手順（FCTM：G/S に乗ってからミスト・アプローチの高度。それまで MCP は会合高度か許可された高度）によるもので、VNAV の経路と X-Plane の G/S の約 0.6 ドットの差は、気圧（標準）と気温（ISA）では説明できず、まだ調べる。筋書きを 2 回目に向けて直した：ILS06LZ の遷移 ATVID（STAR とつながる）、MCP を T/D の前に STAR の 4,000 ft、on approach で ILS06LZ の会合高度 1,300 ft、G/S の捕捉でミスト・アプローチの 3,000 ft、APP の後に A/P CMD C・R。

## 2. s198：RJAA 34L → RJBB 06L（2026-11-01、2 回目）

- 筋書き：1 回目を直したもの（STAR ATMUGA の ATVID から ILS06LZ、T/D の前に MCP 4,000 ft、on approach で MCP 1,300 ft、G/S の捕捉でミスト・アプローチの 3,000 ft、APP の後に A/P CMD C・R）。LF1（降下の減速）の後。
- 結果：進入で失敗（筋書きを 3,943 s で止めた）。Log.txt に Lua の誤りなし。
  - 離陸から巡航：VNAV SPD・LNAV、FL250 の巡航は ±12 ft（6,478 回の取得）。
  - T/D：FL250 のまま 333 kt から降下速度 296 kt へ約 40 秒で水平に減速し（FCOM p.1264 の 2：LF1 の直しどおり）、その後 VNAV PTH で約 -2,300 fpm。
  - ATMUG（XAC からの 268° から STAR の 111° へ、左 157° の旋回。点の上を通って回る）：旋回の間に E/D までの距離が 58.7 から 61.8 NM に増え、VNAV は経路の下最大 2,012 ft、約 30 秒水平に飛んだ（1 回目の見つけたこと 3 と同じ）。旋回は 200° 回って約 16 NM 飛び、距離は 4.3 NM しか減らなかった（旋回の道のりが約 12 NM 長い）。
  - 10,000 ft：253.5 kt で通過（目標 240 kt。減速の始まりが 10,475 ft で、計画より約 225 ft 低かった：旋回の後、経路の約 100 ft 下にいたため。s202 では 240.5 kt）。
  - 進入：MCP 4,000 ft で、3° の経路の 4,000 ft（滑走路から約 12.4 NM）から水平になり、on approach（約 9 NM）までに経路の上 1,020 ft。on approach で MCP 1,300 ft にしたところ、高度セレクターを押さずに VNAV が降下を続けた（AFDS：水平になったときに経路の下だった扱いで、FCOM p.665 の「経路の上にいれば押しが要る」と違う）。同じ秒に速度介入 210 kt、フラップ 1・5、APP、CMD C・R、LOC がすでに捕捉で（待ちが 0 秒で通り）フラップ 20・MCP 170 kt・脚下げまで 241 kt で一度に入り、VNAV SPD の減速で +1,252 fpm、約 250 ft 上がった。経路の上約 2,000 ft、G/S のアンテナから 4.9 NM の 3,400 ft（仰角 6.5°）で G/S を「捕捉」した（X-Plane の偽の G/S の山を拾ったとみられる：推定）。滑走路の上を 2,500〜3,000 ft で越え、滑走路の先の海上へ G/S のモードで降り、LAND 3 は滑走路の先 400 ft で出た。X-Plane を一時停止して止めた。
- 見つけたこと：
  1. 旋回の道のりが VNAV の距離に入っていない（1 回目の 3 の再現）。→ LF2 で直す（旋回の道のりを予測と E/D までの距離に入れる）。
  2. 降下で MCP 高度に水平になった後、経路の上で MCP を下げただけで降下を続けた（FCOM p.665 と違う）。→ LF2 で直す。
  3. 10,000 ft の速度超過（1. の結果）。
  4. 筋書き：MCP を on approach まで 4,000 ft にしたため経路の上に出た。進入の形態を LOC の捕捉で一度に入れた（LOC がすでに捕捉なら待ちが 0 秒）。→ 3 回目では、10,000 ft の下で MCP を 1,300 ft にし（VNAV は STAR の制限を自分で守る）、フラップは速度に合わせて順に、G/S は下から捕まえる。

## 3. s198：RJAA 34L → RJBB 06L（2026-11-01、3 回目）

- 筋書き：2 回目を直したもの（10,000 ft の下で MCP 1,300 ft、on approach で速度介入 210 kt とフラップ 1、225 kt の下でフラップ 5 と APP、G/S が下から 1 ドットで脚とフラップ 20、G/S の捕捉が 0.5 ドット以内かを確かめる）。LF2a・LF2b（降下の VNAV ALT、旋回の道のり）の後。記録は `tests/flight/runs/20261101_215614_s198_line_flight_rjaa_rjbb_747-400_custom/`（session.csv、runner.log）。
- 結果：進入で止めた（形態を作れないまま 1,400 ft で 255 kt・フラップ 1・脚上げ。筋書きを約 3,700 s で止めた）。Log.txt に Lua の誤りなし。
  - 離陸から巡航：VNAV SPD・LNAV、FL250 の巡航は ±12 ft（6,861 回の取得）。
  - T/D：FL250 のまま 333 kt から降下速度へ水平に減速し、VNAV PTH へ。降下の始めの経路の上へのずれは最大 +354 ft（ピッチを下げる遅れ）で、約 2 分で戻った。
  - ATMUG（275° から 74° へ、左 201° の旋回）：経路のずれは −85〜+79 ft（2 回目は −2,012 ft）。E/D までの距離は旋回の間も単調に減った。LF2b（旋回の道のり）のとおり。
  - 10,000 ft：約 246 kt で通過（目標 240 kt。2 回目は 253.5 kt）。減速の区間で経路の下最大 −220 ft。
  - 10,000 ft の下：VNAV PTH・アイドルで、経路（9,800〜2,600 ft の平均 2.90°、重量 260 t）を保つと速度が 240 kt から 251〜252 kt に上がり、DRAG REQUIRED が出た。FCOM p.1260（11.31.26）の「最初の速度制限の下では目標 +10 kt を超えると DRAG REQUIRED、遷移速度（250 kt）+5 kt まで速度で経路を保つ」のとおりで、VNAV の誤りではない。この重量では 240〜250 kt が最小抗力の速さに近く、経路の角度のわずかな違い（約 0.1°）で釣り合いの速さが 10 kt 以上ずれる。
  - on approach（約 3,000 ft、滑走路の約 9 NM 手前）：速度介入 210 kt とフラップ 1 にしたが、3° の経路の上でアイドルでは減速できず、255〜258 kt のまま 1,400 ft（MCP 1,300 ft の VNAV ALT）まで降りた。225 kt の下を待つ間に進入の形態を作れなかった。
- 見つけたこと：
  1. 筋書き：DRAG REQUIRED でスピードブレーキを使っていない（FCOM の DRAG REQUIRED は「抗力が要る」：乗員の操作）。進入の減速も on approach（約 9 NM）からでは遅く、スピードブレーキなしでは経路の上で減速できない。→ 4 回目では、E/D の手前で速度介入 210 kt とスピードブレーキで減速し、フラップ 1・5 を早めに出す（FCTM の降下と進入の減速）。
  2. 2 回目の 1・2（旋回の道のり、降下の VNAV ALT）は直っている。10,000 ft の速度も目標に近づいた。
  3. 着陸・ROLLOUT・停止後の逆推力の表示は、2 回目に続いて確かめられていない（4 回目で）。

## 4. s198：RJAA 34L → RJBB 06L（2026-11-01、4 回目）

- 筋書き：3 回目を直したもの（E/D の 28 NM 手前で速度介入 210 kt とスピードブレーキ FLT DETENT、215 kt の下でフラップ 1 とスピードブレーキ DN、on approach の後 225 kt の下でフラップ 5 と APP、G/S の捕捉でフラップ 30・155 kt・脚下げ・オートブレーキ 3）。
- 結果：58/61。着陸と停止まで飛んだ（初めて）。Log.txt に Lua の誤りなし。
  - 離陸から巡航・T/D・ATMUG の旋回・10,000 ft の下までは 3 回目と同じ（FL250 の巡航は 24,989〜25,012 ft）。
  - 減速：スピードブレーキで 9,000 ft から 215 kt まで落ちた（3 回目は 255 kt のまま）。MCP 1,300 ft で VNAV ALT、フラップ 5 のまま 1,300 ft を約 80 秒、213〜220 kt で水平に飛んだ（速度介入 210 kt に下がり切らない）。
  - G/S の捕捉：1,298 ft・213 kt。捕捉のときの G/S の偏位 -0.94 ドットで、0.5 ドット以内の確かめが落ちた。
  - 最終進入：捕捉と同時にフラップ 30（216 kt：フラップ 30 の制限速度を超える）と 155 kt にしたが、G/S の上（-1,100〜-1,300 fpm）でアイドルのまま 75 秒で 182 kt までしか落ちず、50 ft を 182 kt（VREF 30 の約 146 + 5 より 30 kt 速い）で通った。
  - FLARE：59 ft で FLARE。速すぎて浮き上がり、13 ft から 18.7 ft まで上昇（+290 fpm）、その後 FLARE がピッチを -3.3° まで下げ、174 kt・-525 fpm・ピッチ -3.2° の機首下げで接地した。
  - ROLLOUT：接地と同時に FMA のロール・ピッチのモードが全部消え（A/P は入ったまま）、ROLLOUT にならなかった。滑走の LOC の偏位は 0.125〜0.224 ドット（0.2 ドットの確かめが落ちた）。スピードブレーキは自動で UP、逆推力で停止。
- 見つけたこと：
  1. 筋書き：進入の形態と減速が FCTM と違う。FCTM p.161（Approach）：LOC を捕まえに行くときにフラップ 5、G/S alive で脚下げ・フラップ 20 でフラップ 20 の速度へ減速、G/S の捕捉で着陸フラップと VREF + 5。4 回目は 213 kt で G/S を捕まえ、そこで一度にフラップ 30 にした。→ 5 回目は FCTM の順にする（G/S の前にフラップ 5 の速度、G/S alive でフラップ 20）。
  2. 着陸形態（フラップ 30・脚下げ）・アイドルの 3° の経路で、180〜215 kt の減速が毎秒 0.35〜0.76 kt と小さい（抗力が小さい疑い）。L/D に直すと 11〜14 ほど（747 の着陸形態は 7 前後と見られる：推定）。FCTM の数値（p.139：水平・クリーンで 340 → 250 kt に 90 秒）との突き合わせと、カスタム acf の着陸形態の抗力を notes/AERO.md で調べる。
  3. FLARE の則：速すぎる進入で浮き上がった後、機首を -3.3° まで下げて機首下げで接地した。FLARE はピッチを下げる側を抑える（FCOM・ATA22 の FLARE の記述と照らす）。notes/ATA-22.md で直す。
  4. ROLLOUT：接地の瞬間に AFDS がモードを消した（RA 6.7 ft → 接地で 4.8 ft、RA 5 ft の下で ROLLOUT になる前に地上のリセットが先に来た）。LAND 3 で ROLLOUT が armed なら、接地でも ROLLOUT にする（FCOM の ROLLOUT は RA 5 ft の下）。notes/ATA-22.md で直す。
