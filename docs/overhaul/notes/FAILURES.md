# 故障の窓（PROGRESS の「次にやること」15）

2026-11-04 に利用者と決めたこと：
- この機体専用の故障の窓を作る。X-Plane の Plugins → 747-400 から開く浮動ウィンドウで、ATA の章（のちに系統図）から故障を入れる。
- 見た目は EICAS 風でも明るい EFB 風でもよい。色と言葉で状態が分かること。
- 先に、再現しきれていない系統（APU・燃料など）を仕上げる。
- 他の製品の絵は写さない。
- Windows だけ。

## 1. 段取り

- F0：各モデルに故障の入力を足す。済（2026-11-04）。
  - 電源 ATA-24 §11、燃料 ATA-28 §11、空圧 ATA-36 §10、空調 ATA-21 §10、脚 ATA-32 §17、EEC ATA-70-80 §10、APU ATA-49 §11、オイルフィルタ ATA-70-80 §11、油圧 ATA-29 §10。
  - 前からあったもの：火災、操縦系統、表示、航法など。
- F1：窓・メニュー・章ごとの一覧と、すぐ入れる・直す。済（2026-11-04、§2〜§5）。
- F2：後で起こす（arm）：時間・高度・速さ・ランダム、arm を解く。済（2026-11-04、§6）。X-Plane の MTBF（平均故障間隔）の形はやめ、「N 分以内のどこか」にした（訓練で使いやすい）。
- F3：系統図から入れる。済（2026-11-04、§7）：油圧・電源・燃料・空圧の図。ほかの章は一覧だけ。

## 2. 窓（F1、2026-11-04）

置き場所と開き方：
- 本体はネイティブのプラグイン `plugins/b747_fms_bridge`（機体のフォルダの中。この機体を読み込んだときだけ動く）の `src/failures_window.c`。
- 開き方は 2 つ。
  - X-Plane のメニュー Plugins → 747-400 → Failures...
  - コマンド `laminar/B747/failures/window_toggle`。キーやボタンに割り当てられる。

窓の扱い：
- X-Plane の枠の中の浮動ウィンドウで、動かせて大きさも変えられる（いちばん小さくて 700×400。arm の帯が収まる大きさ。F3 から）。
- X-Plane の枠（題、閉じるボタン、右上の POP OUT のボタン）の中に出る。POP OUT で OS の別の窓になり（別のモニタへ）、もう一度押すと戻る。
- VR を使っているときは VR の中に出る。

画面の作り（EICAS 風：暗い地、白い字）：
- 左に章の一覧。故障中の数を琥珀の札で出す。
- 右に選んだ章の故障を、群（シアンの見出し）ごとに並べる。
- 各行の右に状態を出す。
  - NORMAL：緑の枠。
  - FAILED：琥珀の地。
  - ARMED：シアン。この窓で arm したもの（F2、§6）と、X-Plane の故障画面で MTBF などに arm されたもの。
  - N/A：灰。その dataref が無い。
- 行をクリックするとすぐ故障になり、もう一度クリックすると直る。ARMED の行は arm が解ける。
- 上に全体の故障の数（無ければ ALL NORMAL）と REPAIR ALL のボタン。
  - REPAIR ALL は一覧の故障を全部直し、arm も解く。
  - X-Plane の `fix_all_systems` は使わない。モデルが X-Plane の故障を自分で書く所があっても、それを消さないため。
- マウスのホイールで、章の一覧と故障の一覧をそれぞれ送る。
- 字は ASCII だけ（X-Plane の字体）。名前はこの機体の EICAS・パネルの英語の呼び方に合わせた。

試験と外からの操作：
- `laminar/B747/failures/window_open`（int）：0 閉、1 X-Plane の窓の中、2 POP OUT した別の窓、3 VR の中。1・0 を書くと開く・閉じる。
- `laminar/B747/failures/active`（int、読むだけ）：一覧の故障のうち故障中の数。
- コマンド `laminar/B747/failures/repair_all`：REPAIR ALL と同じ。
- `laminar/B747/failures/test_click`（int、試験用）：窓が最後に描いた物の真ん中を、窓のクリックの処理（マウスと同じ関数）に渡す。1000 + n は章 n（0 から）、2000 + n は表示中の章の行 n（0 から、群の見出しも数える）、3000 は REPAIR ALL（POP OUT は X-Plane の枠のボタン）。読むと押した値、描かれていなければ -1。

## 3. 一覧（`plugins/b747_fms_bridge/failures.txt`）

- 窓を開くとき、ファイルが変わっていれば読み直す（arm したものは残す）。故障を足すのに、プラグインを作り直さなくてよい。
- 書き方（ファイルの頭にもある）：
  - `C <章> <題>`：章。
  - `G <題>`：群。
  - `F <dataref>[<添字>] <種類> <名前>`：故障。種類は次の 3 つ。
    - `on`：この機体のモデルの故障。1 が故障、0 が正常。
    - `xp`：X-Plane の故障。6 が今の故障、0 が正常。1〜5 は ARMED。
    - 数：その値が故障、0 が正常。安定板トリムの暴走は -1 が機首下げ、1 が機首上げ。
- （F3）章の故障の後に、その章の系統図を書ける（`D` で始め、`L` 線・`T` 字・`B` 箱。書き方はファイルの頭、§7）。
- dataref は、初めて要るときに探す。XTLua の dataref はプラグインの起動より後にできる。無いときは 1 秒ごとに探し直す。
- どちらの故障を載せるかの方針：
  - この機体のモデルが作っている系統は、モデルの故障（`laminar/B747/.../fail`）。
  - X-Plane が作っている系統や、モデルが X-Plane の故障を入力として読む所は、X-Plane の故障。
    - 例：エンジン火災、タイヤ、防氷のヒーター、ピトー・静圧の詰まり、AOA、受信機、油ポンプ、点火、逆推力、急減圧。
  - 同じものに両方があるときは、モデルの方だけを載せる。
    - 例：ADC、IRU、GPS、トランスポンダ、電波高度計、発電機、脚の作動、油圧の漏れ、安定板トリム。
- 一覧は 14 章（21・24・26・27・28・29・30・31・32・34・35・36・49・70-80）、399 項目（F1 は 13 章 336 項目。2026-11-04 夜に 35 OXYGEN と、エンジンの flameout・故障・燃料フィルタを s245 で確かめて足し（349）、原因を作っていなかった故障 50 を足した：§8）。2026-11-10 に EGT と点火器の 16 項目を足して 415（§9）。
- X-Plane の故障で載せたのは、モデルが読んでいる、または X-Plane の試験で効き方を確かめたものだけ。
  - 試験：s08（点火）、s75・s76（油ポンプ）、s22（火災）、防氷・航法の各シナリオ。
- まだ載せていないもの。どう効くかを X-Plane で確かめてから足す。
  - ブレーキ（`rel_lbrakes`・`rel_rbrakes`）。
  - 自動操縦・通信の X-Plane の故障。
- s245（2026-11-04、X-Plane で確かめて足したもの。成田でエンジン運転中）：
  - 燃料フィルタ（`rel_fuel_block0`）：ENG 1 FUEL FILT が出て、エンジンは回り続ける（N2 69.7 %、燃料流量 0.11 kg/s）。実機のフィルタの bypass と同じ形。
  - 乗客の酸素（`rel_pass_o2_on`）：PASS OXYGEN ON。故障を消しても、RESET（12,000 ft 未満）まで残る（実機どおり：notes/ATA-35.md）。
  - エンジンの flameout（`rel_engfla0`）と故障（`rel_engfai1`）：すぐ止まり、ELEC GEN OFF が出る。故障を消しても自分では点かない（ふつうの始動の手順で）。

## 6. 後で起こす（F2、2026-11-04）

使い方：
- 正常な故障の行には、状態の左に ARM のボタンがある。押すと窓の下に arm の帯が出る。
- 帯で選ぶもの：
  - 引き金：IN TIME（今から N 分）、AT ALTITUDE（指示高度）、AT SPEED（指示対気速度）、RANDOM（N 分以内のどこか。いつかは出さない）。
  - 値：- と + で変える。
    - 分：1・2・3・5・10・15・20・30・45・60・90・120。既定は IN TIME 5 分、RANDOM 30 分。
    - 高度：1000 ft ごと（0〜45,000 ft）。既定 10,000 ft。
    - 速さ：10 kt ごと（40〜400 kt）。既定 100 kt。
  - ARM で arm、CANCEL でやめる。
- arm した行は ARMED（シアン）になり、左に引き金を出す（IN 4:32 の残り時間、ABOVE 1000 FT、BELOW 250 KT、RANDOM）。章の一覧と上の欄にも、arm の数をシアンで出す。
- arm した行を押すと arm が解ける。REPAIR ALL も arm を解く（arm だけがあるとき、REPAIR ALL はシアン。F3 から）。

決まり：
- 時間はシムの時間（`sim/time/total_running_time_sec`）。一時停止の間は進まない。
- 高度・速さは機長側の指示値（`sim/cockpit2/gauges/indicators/altitude_ft_pilot`・`airspeed_kts_pilot`）。
  - arm したときの値の側から、その値を横切ると起きる。下から arm すれば「以上」、上からなら「以下」。
- 窓を閉じていても起きる。プラグインの毎フレームの処理（`fw_poll`）が、1 秒に 5 回調べる。
- 機体を読み直すと arm は消える（プラグインが起動し直す）。

試験と外からの操作：
- `laminar/B747/failures/armed`（int、読むだけ）：arm している数。
- `laminar/B747/failures/arm_value`（int、読むだけ）：帯の値（分・ft・kt）。帯が無ければ -1。
- `test_click` に足したもの：4000 + n は行 n の ARM、5000 + k は帯の引き金 k（1 時間、2 高度、3 速さ、4 ランダム）、6000 は -、6001 は +、6002 は ARM、6003 は CANCEL。

試験：
- X-Plane（カスタム acf）：`s243_failure_arm`（成田 34L、エンジン運転中）。
  - IN TIME 1 分：ENGINE PUMP 1 が 1 分で故障。
  - RANDOM 1 分以内：ENGINE PUMP 2。
  - AT ALTITUDE 1000 ft：ENGINE PUMP 3。気圧設定を 1 inHg 上げて、指示高度を約 1000 ft 上げる。
  - 行を押して arm を解く：ENGINE PUMP 4 は故障にならない。
  - AT SPEED 40 kt：離陸滑走で X-Plane の ICE DETECTORS（`rel_ice_detect` が 6）。
  - REPAIR ALL で故障も arm も消える。

## 7. 系統図（F3、2026-11-04）

使い方：
- 図のある章（29 油圧・24 電源・28 燃料・36 空圧）では、上の欄に LIST と DIAGRAM のボタンが出る。DIAGRAM で右に図を出す。選んだ形は章を替えても残り、図の無い章では一覧になる。
- 図の箱が 1 つの故障。色は一覧と同じ（緑の枠が正常、琥珀が故障、シアンが arm）。
- 箱を押すと、すぐ故障・もう一度で修理（一覧の行と同じ）。
- 右クリックで arm の帯が出る（正常な箱だけ）。一覧の行の右クリックも同じ。
- 線と字は系統の形を見せるだけ。実機の synoptic の絵は写していない（自分で引いた簡単な図）。
- 図には主な部品だけ。故障のやり方がいくつかある部品（PRV の閉・開など）は、図では 1 つ（閉）だけで、ほかは一覧から。

図の中身：
- 29 油圧：系統 1〜4 ごとに、リザーバ（漏れ）、EDP、demand pump（1・4 は ADP、2・3 は ACMP）。
- 24 電源：エンジン 1〜4 ごとに IDG・発電機・AC bus、同期バスと SSB、TRU 1〜4、充電器 2 つ。
- 28 燃料：主タンクのポンプ（前・後）、override/jettison のポンプ、crossfeed の弁、エンジンの spar 弁、中央とスタビのポンプ、投棄の弁とノズル。
- 36 空圧：エンジン 1〜4 ごとに HPSOV・PRV（閉のまま）と抽気の過熱、左・中央・右のダクトの漏れ、APU の空気。

一覧のファイルの書き方（図）：
- 画布は幅 1000・高さ 700、y は下向き。窓の右の欄に、縦横比を保って収める。
- 書いた順に描く。線を先に書くと箱の下になる。
- `L` は水平か垂直の線だけ。`T` と `B` の字は 63 字まで（1 回目の試験では 23 字で切れていた）。
- `B` の故障は、その章の一覧に同じ dataref と種類で載っていること。載っていない箱は読まない。

試験と外からの操作：
- `test_click` に足したもの：7000 + n は図の箱 n（0 から、箱だけを数える）、8000 は LIST、8001 は DIAGRAM、9000 + n は箱 n の右クリック。
- X-Plane（カスタム acf）：`s244_failure_diagram`。
  - 章 29 で DIAGRAM：EDP 2 の箱で故障（HYD PRESS ENG 2）と修理、RSVR 1 の箱の右クリックで arm の帯、CANCEL。
  - 章 24：GEN 3 と SSB の箱。章 28：X FEED 2 の箱。章 36：中央ダクトの漏れの箱。
  - 図の無い章 21 では LIST・DIAGRAM のボタンが出ず、一覧の行を押せる。
  - REPAIR ALL、章 29 に戻って LIST。
  - 図の写真を撮る。

## 8. 原因を作っていなかった故障（2026-11-04 夜）

- メッセージの論理（や FCOM の条件）はあるのに、原因になる物理（冷却、漏れ、弁やスイッチの固着）を作っていなかったので出なかった故障に、故障の入力を足した（利用者の依頼：「似たような理由で追加してない故障も全部実装だけ」）。原因はそれぞれ最小の形で作り、そこから先は前からの論理に任せる。速さなど資料に無い値は推定（各系統の notes）。
- 一覧に足した 50 項目（どれも各章の終わりに足したので、前のシナリオの行の番号は変わらない）：
  - 21：OUTFLOW VALVE L/R AUTO DRIVE、UPPER/LOWER RELIEF VALVE STUCK OPEN、FLIGHT DECK HUMIDIFIER（P&W、RR）（ATA-21.md §11）。
  - 26：消火ボトル 9 本の漏れ（ATA-26.md §13）。
  - 27：greenband の前脚圧スイッチが FWD／AFT を読む（ATA-27.md §20）。
  - 29：系統 1〜4 の作動油の過熱（ATA-29.md §11）。
  - 31：離陸警報カード（ATA-27.md §20）。
  - 34：ILS アンテナの relay（LOC と G/S、L・C・R）（ATA-34.md §22）。
  - 35：乗員と乗客の酸素ボンベの漏れ（ATA-35.md §11）。
  - 49：APU の吸気ドアの固着（ATA-49.md §12）。
  - 70-80：油の過熱、idle（minimum のまま、approach のまま：メッセージだけ）、start valve の開・閉の固着（ATA-70-80.md §12、ATA-36.md §12）。
- 足さなかったもの：

  - >SMOKE LAVATORY：前から火災の故障（`fire/fail/lav_smoke`）で advisory 264 が出る。caution の表の 53 は古い重複で、使わない。

## 9. EGT と点火器の故障（2026-11-10：EGT の作り直し、ATA-70-80.md §13）

- 利用者の「EGT ロジックいじれば Hot Start 故障も再現できる？」「入れよう」「b と c も入れよう」（b は EGT の過熱、c は着火しない始動）。
- 一覧に足した 16 項目（399 → 415）。どれもこの機体のモデルの故障（`on`）：
  - 70-80 の群 IGNITION AND REVERSERS に、点火器 1・2 を 4 発分（`laminar/B747/engines/fail/igniter[0..7]`：0〜3 が各エンジンの点火器 1、4〜7 が 2）。X-Plane の ENGINE n IGNITERS（2 本とも）の後ろ。
  - 新しい群 START AND EGT に、HOT START（`engines/fail/hot_start[0..3]`）と EGT OVERTEMP（`engines/fail/egt_high[0..3]`）。名前に「(P&W, GE)」：RB211 の EGT は前のまま（資料なし）で、この 2 つは効かない。

- どう効くか：
