## 気づいたこと

- FMC-2 の今の作り方（すぐ後ろの制限だけを見る）は、制限が多い STAR で大きく外れる（ランダムな STAR 300 本で 215 件。6 NM ごとに 900 ft ずつの例では 24 個中 16 個）。担当の例は、その一部が見えたもの。直すには、経路の形（後ろの制限の上限で折る）と、速度制限の減速の置き方（FMC-08：アイドルで減速できる所に置く）を一緒に作り直す必要がある。後の課題として残す。
- EEC-1 の最大推力の上限（定格の 1.1 倍）は推定。X-Plane の s271（PW、FL370）で読んだ最大推力は 254,420 N で、定格 254,000 N の 0.2 % 上だった（上限は 279,400 N）。
- X-Plane の確かめで、レビューの範囲の 11-10 の変更（d250e305：EEC の推力の制御を X-Plane のエンジンに合わせた）の退行が見つかった。担当は指摘していなかった。A/T のアイドル（レバー 0.12°）で指令がアイドルより上（海面で 0.0013 EPR、FL250 で約 0.003）だったので、小さくした利得のループでスロットルを 25 秒かけて下げ、s202 の T/D の水平の減速が遅れた（降り始め 316 kt）。ATA70_80 p.151 の FLAT IDLE（TLA 2° まで）を入れて直した（`8959c8f2`、notes/ATA-70-80.md §21）。
- EEC-5・AERO-2 の直しは、XTLua の「Reload Scripts」が `aircraft_unload` を呼ぶことを前提にしている。呼ばれなければ、何も変わらない（悪くもならない）。
