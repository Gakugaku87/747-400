## 見る所（型ごと）

- F：
  - 本家から引き継いだ、出典の無い式・係数・表（FMS・EEC・表示・重量重心）。例：`calc_stab_trim`、`calc_CGMAC` の翼の寸法と LEMAC、`N1_display_PW`（notes/AERO.md §3.16 で出所不明）、多項式の当てはめ。それが乗員の見る値か、機体を動かす値かも分ける。
  - プラグインと X-Plane のあいだの単位と換算（units と度、比と角度、kg と lb、% MAC の基準、ft と m）。controlObject の写し（`B747.19.xt.hydraulicsmodel.lua` の `minout`・`maxout`・`scale`）を、資料の舵角と範囲に照らす。
  - 資料と 1 点でしか比べていない値：重い・軽い、前・後ろの重心、寒い・暑い、高い所。前のレビューの型 A（運用の端）と重なる所は、その結果も見る。
- G：
  - カスタム acf のパネル（`747-400_custom.acf` の GROUP の部分）の `gen_pointer`・`gen_tape`・`gen_rotary`・`gen_LED` などで、key frame の両端が平らでないもの（2 点だけ、片端だけ平ら）と、その dataref が範囲の外に出る場合（アイドル、逆推力、エンジン停止、電源断の 0、故障、始まりの値、時間加速）。key frame を拾うスクリプトは、リポジトリの外の作業用フォルダーで書いて回す。
  - `CLIP` の無いテープ。表示の dataref を Lua が範囲の外に書く所。
  - 3D（OBJ）は変えない範囲なので、プラグインが書く dataref が 3D の想定する範囲（INTERFACES.tsv）を出ないかだけを見る。
- H：
  - CDU のページ（`activepages/*.lua`、`B744.fms.pages.lua`、`atc/`）の固定の文字（`*`、`-`、`XXXX`、決め打ちの数字・名前）を、FCOM の図と本文の行に突き合わせる。notes/ATA-34-61-CDU.md のページの表の「固定」「伏せ字」「未」も手がかり。
  - EICAS・ND・PFD の固定の文字・画像で、実機はデータを出すもの。
- I：
  - コードの注釈とノートの「出さない」「省く」「表示しない」「空白」「estimate」のうち、出典の無いもの。
  - 片方の場合だけ作った非対称。例：高度だけの制限の点は予測の速さを出すのに、速さだけの制限の点は予測の高度を出さない。
- J：
  - 段階に結び付いた選択・旗・表示（離陸の減格と SEL、V 速度とバグ、TAKEOFF REF の値、進入の VREF と FLAP/SPEED、TO/GA、進入復行、待機、RTA、E/O、autobrake の RTO）が、FCOM の「いつ消える」（例：p.1273 の上昇の減格、p.1236 の flight complete）のとおりに消えるか。消えない所と、早く消えすぎる所の両方。
  - 離陸のための判定（離陸形態警報、V1 による抑止、離陸の推力の判定、離陸の後の抑止の時間）が、着陸の滑走・逆推力・RTO・タッチアンドゴー・着陸復行で働かないか。逆か前進かの判定がレバーだけで、逆推力の扉やエンジンの回転の戻りを見ていない所。
  - 前進推力の表示と警報の規則（max EPR・N1 の赤、指令の線、推力の不足や超過の警報）が、逆推力とその戻りで働かないか。
  - 試験の穴：着陸の滑走（接地、自動スピードブレーキ、逆推力いっぱいから reverse idle・格納、autobrake）を通しで見るシナリオが無い（`s12_reverser` は止まったまま）。
